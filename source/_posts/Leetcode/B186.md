## 3978 - Unique Middle Element

**题意**

题目链接：[Unique Middle Element](https://leetcode.com/problems/unique-middle-element/description/)

给定一个长度为奇数的整数数组 `nums`。若数组中间元素在整个数组中恰好出现一次，返回 `true`；否则返回 `false`。

- $1 \le n=\textit{nums.length}\le 100$
- $n$ 为奇数。
- $1 \le nums_i\le 100$

**解题思路**

中间下标为 `n / 2`。取出对应元素后遍历整个数组统计其出现次数即可；一旦计数达到 $2$，就可以提前返回 `false`。

**代码**

```cpp
class Solution {
public:
    bool isMiddleElementUnique(vector<int>& nums) {
        int x = nums[nums.size() / 2];
        int cnt = 0;

        for (int v : nums) {
            if (v == x && ++cnt == 2) {
                return false;
            }
        }

        return true;
    }
};
```

**复杂度分析**

时间复杂度：$O(n)$。

空间复杂度：$O(1)$。

**变形**

如果需要判断某个指定下标的元素是否唯一，直接将中间下标替换为该下标即可。若要同时回答多个值的出现次数，可以预处理哈希表。

## 3979 - Maximum Valid Pair Sum

**题意**

题目链接：[Maximum Valid Pair Sum](https://leetcode.com/problems/maximum-valid-pair-sum/description/)

给定长度为 $n$ 的整数数组 `nums` 和整数 `k`。选择满足 $0\le i<j<n$ 且 $j-i\ge k$ 的下标对 $(i,j)$，求 `nums[i] + nums[j]` 的最大值。

- $2\le n\le 10^5$
- $1\le nums_i\le 10^9$
- $1\le k\le n-1$

**解题思路**

固定右端点 $j$。合法左端点满足：

$$
i\le j-k
$$

因此，只需要知道前缀 `nums[0..j-k]` 中的最大值。扫描 $j=k,k+1,\ldots,n-1$ 时，先将 `nums[j-k]` 加入前缀最大值 `mx`，再用 `mx + nums[j]` 更新答案。

每个合法下标对都会在其右端点被处理；而 `mx` 正是该右端点下所有合法左端点的最优选择，所以取遍所有右端点即可得到全局最优值。

**代码**

```cpp
class Solution {
public:
    int maxValidPairSum(vector<int>& nums, int k) {
        int n = nums.size();
        int mx = 0;
        int ans = 0;

        for (int j = k; j < n; j++) {
            mx = max(mx, nums[j - k]);
            ans = max(ans, mx + nums[j]);
        }

        return ans;
    }
};
```

**复杂度分析**

时间复杂度：$O(n)$。

空间复杂度：$O(1)$。

**变形**

如果约束改为 $j-i\le k$，合法左端点变成一个滑动窗口，可以用单调队列维护窗口最大值。若要求最大乘积或最小和，维护的前缀信息也相应改为所需的最值。

## 3980 - Minimum Operations to Transform Binary String

**题意**

题目链接：[Minimum Operations to Transform Binary String](https://leetcode.com/problems/minimum-operations-to-transform-binary-string/description/)

给定等长二进制字符串 `s1`、`s2`。可以对 `s1` 任意次执行以下操作：

- 将任意一个 `'0'` 变为 `'1'`；
- 将一对相邻的 `'1'` 变为 `'0'`。

求将 `s1` 变为 `s2` 的最少操作次数；若无法完成则返回 `-1`。

- $1\le n\le 10^5$
- `s1` 和 `s2` 仅包含 `'0'`、`'1'`。

**解题思路**

设 `s1`、`s2` 中 `'1'` 的数量分别为 $a,b$，两类操作的使用次数分别为 $x,y$。第一类操作使 `'1'` 数量增加 $1$，第二类操作使其减少 $2$，因此：

$$
b=a+x-2y
$$

总操作次数可以写成：

$$
x+y=b-a+3y
$$

$a,b$ 已经确定，问题变成最小化第二类操作次数 $y$。

令 $D$ 为所有满足 `s1[i] == '1' && s2[i] == '0'` 的位置。第一类操作无法将 `'1'` 变为 `'0'`，所以 $D$ 中的每个位置都必须作为端点参与至少一次第二类操作。

把每个位置视作链上的顶点，每一对相邻位置视作一条边。现在需要选择最少的边覆盖集合 $D$。从左向右处理最靠左的未覆盖位置 $i$：

- 若 $i+1<n$，选择边 $(i,i+1)$；
- 否则只能选择边 $(i-1,i)$。

对于存在右边界的 $i$，任何方案都必须选择一条与 $i$ 相邻的边。选择右边的边不会影响已经处理的位置，并且还可能覆盖后续的必要位置，因而不劣于选择左边的边。由此得到最少边数 `edg`，答案为：

$$
b-a+3\cdot edg
$$

当 $n=1$ 时无法执行第二类操作，只有 `"1" -> "0"` 无解，单独处理即可。

**代码**

```cpp
class Solution {
public:
    int minOperations(string s1, string s2) {
        int n = s1.size();
        int dif = 0;

        for (int i = 0; i < n; i++) {
            dif += (s2[i] - '0') - (s1[i] - '0');
        }

        if (n == 1) {
            return s1 == "1" && s2 == "0" ? -1 : dif;
        }

        vector<int> covered(n);
        int edg = 0;

        for (int i = 0; i < n; i++) {
            if (s1[i] != '1' || s2[i] != '0' || covered[i]) {
                continue;
            }

            edg++;

            if (i + 1 < n) {
                covered[i] = covered[i + 1] = 1;
            } else {
                covered[i - 1] = covered[i] = 1;
            }
        }

        return dif + 3 * edg;
    }
};
```

**复杂度分析**

时间复杂度：$O(n)$。

空间复杂度：$O(n)$。

**变形**

如果第二类操作能同时清除长度为 $k$ 的连续 `'1'` 段，仍可先由 `'1'` 数量写出操作次数关系，再将必须清除的位置转化为链上的区间覆盖问题。若每种操作的代价不同，则需要在覆盖模型上进一步做带权 DP。

## 3981 - Count Distinct Ways to Form Target from Two Strings

**题意**

题目链接：[Count Distinct Ways to Form Target from Two Strings](https://leetcode.com/problems/count-distinct-ways-to-form-target-from-two-strings/description/)

给定 `word1`、`word2` 和 `target`。对 `target` 的每个字符，从两个单词之一选择一个相同字符；同一个单词中被选择的下标必须严格递增，且两个单词都至少选择一次。求不同方案数，对 $10^9+7$ 取模。

- $1\le |word1|,|word2|,|target|\le 100$
- 三个字符串均仅包含小写字母。

**解题思路**

先暂时忽略“两个字符串都要使用”的限制，统计所有方案数，最后减去只使用 `word1` 与只使用 `word2` 的方案数。由于 `target` 非空，这两类方案互不相交。

处理完 `target` 的前若干个字符后，定义 $dp_{i,j}$：

- $i=0$：尚未从 `word1` 中选择字符；$i>0$：最后一次选择 `word1[i-1]`；
- $j=0$：尚未从 `word2` 中选择字符；$j>0$：最后一次选择 `word2[j-1]`。

初始状态为 $dp_{0,0}=1$。

设当前需要匹配的字符为 $c$。若选择 `word1[x]`，此前在 `word1` 的最后下标必须小于 $x$，所以：

$$
ndp_{x+1,j}\mathrel{+}=\sum_{i=0}^{x}dp_{i,j}
$$

固定 $j$ 后从左到右维护前缀和，即可在线性时间完成所有 $x$ 的转移。选择 `word2[y]` 时同理：

$$
ndp_{i,y+1}\mathrel{+}=\sum_{j=0}^{y}dp_{i,j}
$$

最终将所有 $dp_{i,j}$ 相加得到所有方案数。只使用单个字符串的方案，恰好是 `target` 作为该字符串子序列的出现次数；使用经典的一维子序列计数 DP 求出后相减即可。

**代码**

```cpp
class Solution {
    static constexpr int MOD = 1000000007;

    int countSubsequence(const string& s, const string& target) {
        int m = target.size();
        vector<int> dp(m + 1);
        dp[0] = 1;

        for (char c : s) {
            for (int j = m - 1; j >= 0; j--) {
                if (c != target[j]) {
                    continue;
                }

                dp[j + 1] += dp[j];
                if (dp[j + 1] >= MOD) {
                    dp[j + 1] -= MOD;
                }
            }
        }

        return dp[m];
    }

public:
    int interleaveCharacters(string word1, string word2, string target) {
        int n = word1.size();
        int m = word2.size();

        vector<vector<int>> dp(n + 1, vector<int>(m + 1));
        dp[0][0] = 1;

        for (char c : target) {
            vector<vector<int>> ndp(n + 1, vector<int>(m + 1));

            for (int j = 0; j <= m; j++) {
                int sum = 0;

                for (int x = 0; x < n; x++) {
                    sum += dp[x][j];
                    if (sum >= MOD) {
                        sum -= MOD;
                    }

                    if (word1[x] == c) {
                        ndp[x + 1][j] += sum;
                        if (ndp[x + 1][j] >= MOD) {
                            ndp[x + 1][j] -= MOD;
                        }
                    }
                }
            }

            for (int i = 0; i <= n; i++) {
                int sum = 0;

                for (int y = 0; y < m; y++) {
                    sum += dp[i][y];
                    if (sum >= MOD) {
                        sum -= MOD;
                    }

                    if (word2[y] == c) {
                        ndp[i][y + 1] += sum;
                        if (ndp[i][y + 1] >= MOD) {
                            ndp[i][y + 1] -= MOD;
                        }
                    }
                }
            }

            dp.swap(ndp);
        }

        int ans = 0;

        for (int i = 0; i <= n; i++) {
            for (int j = 0; j <= m; j++) {
                ans += dp[i][j];
                if (ans >= MOD) {
                    ans -= MOD;
                }
            }
        }

        ans -= countSubsequence(word1, target);
        if (ans < 0) {
            ans += MOD;
        }

        ans -= countSubsequence(word2, target);
        if (ans < 0) {
            ans += MOD;
        }

        return ans;
    }
};
```

**复杂度分析**

设 $n=|word1|$、$m=|word2|$、$l=|target|$。每个目标字符的两部分转移均为 $O(nm)$。

时间复杂度：$O(l\cdot n\cdot m)$。

空间复杂度：$O(nm)$。

**变形**

如果要求恰好使用某一个字符串若干次，可以在状态中加入使用次数维度。若有更多源字符串，状态可扩展为各字符串最后选择位置的笛卡尔积；当维度过高时，通常需要利用字符位置表或稀疏状态进一步优化。
