## 3990 - Rearrange String to Avoid Character Pair

**题意**

题目链接：[Rearrange String to Avoid Character Pair](https://leetcode.com/problems/rearrange-string-to-avoid-character-pair/description/)

给定字符串 `s` 和两个不同的小写字母 `x`、`y`。重排 `s` 得到一个排列 `t`，使 `t` 中每个 `y` 都出现在每个 `x` 之前。返回任意合法排列。

- $1\le |s|\le100$；
- `s` 仅含小写字母；
- `x != y`。

**解题思路**

题目仅限制 `x`、`y` 的相对次序，其他字符没有位置要求。直接将字符分为三组，并按下列顺序拼接：

```text
所有 y + 所有既非 x 也非 y 的字符 + 所有 x
```

所有 `y` 都在首段、所有 `x` 都在末段，因此构造一定满足要求；每个字符恰好被加入一次，结果也是原字符串的排列。

**代码**

```cpp
class Solution {
public:
    string rearrangeString(string s, char x, char y) {
        string ans;

        for (char c : s) {
            if (c == y) {
                ans += c;
            }
        }
        for (char c : s) {
            if (c != x && c != y) {
                ans += c;
            }
        }
        for (char c : s) {
            if (c == x) {
                ans += c;
            }
        }

        return ans;
    }
};
```

**复杂度分析**

时间复杂度：$O(|s|)$。

空间复杂度：$O(|s|)$，为返回字符串所占空间；不计返回值时额外空间为 $O(1)$。

**变形**

若多个字符之间存在类似“所有 `a` 在所有 `b` 前”的偏序约束，可将字符类别视为节点、约束视为边，先拓扑排序得到类别顺序，再按类别分组构造。

## 3991 - Maximum Value of an Alternating Sequence

**题意**

题目链接：[Maximum Value of an Alternating Sequence](https://leetcode.com/problems/maximum-value-of-an-alternating-sequence/description/)

构造长度为 `n` 的整数序列 `seq`，其中 `seq[0] = s`。序列必须严格交替，即：

```text
seq[0] > seq[1] < seq[2] > ...
```

或：

```text
seq[0] < seq[1] > seq[2] < ...
```

并且任意相邻元素之差的绝对值不超过 `m`。求所有合法序列中能够出现的最大元素。

- $1\le n,s\le10^9$；
- $1\le m\le10^5$。

**解题思路**

当 `n = 1` 时，唯一元素为 `s`。

当 `n >= 2` 时，选择 `s < seq[1]` 更优。第一个峰值最大可以取为 `s + m`。

设相邻的两个峰为 `p`、`q`，中间谷值为 `v`。由于序列严格交替且元素为整数：

$$
v\le p-1
$$

又有 $q-v\le m$，所以：

$$
q\le p+m-1
$$

即每经过两个位置，峰值至多增加 `m - 1`。这个上界可以达到：前一个峰为 `p` 时，取谷值 `p - 1`，再取下一个峰 `p - 1 + m` 即可。

长度为 `n` 时，采用先上升的构造共有 `floor(n / 2)` 个峰。因此答案为：

$$
s+\left\lfloor\frac n2\right\rfloor(m-1)+1
$$

例如 `s = 3, m = 5, n = 4` 时，可以构造 `[3, 8, 7, 12]`。

**代码**

```cpp
class Solution {
public:
    long long maximumValue(int n, int s, int m) {
        if (n == 1) {
            return s;
        }

        return 1LL * s + 1LL * (n / 2) * (m - 1) + 1;
    }
};
```

**复杂度分析**

时间复杂度：$O(1)$。

空间复杂度：$O(1)$。

**变形**

若相邻元素不再要求是整数，峰与峰之间可以无限接近 `m` 的增量，严格不等号带来的 `-1` 不再成立；本题的整数条件正是公式中 `m - 1` 的来源。

## 3992 - Minimum Adjacent Swaps to Partition Array

**题意**

题目链接：[Minimum Adjacent Swaps to Partition Array](https://leetcode.com/problems/minimum-adjacent-swaps-to-partition-array/description/)

给定数组 `nums` 和 `a < b`。通过相邻交换将数组划分为连续三段，依次满足：

- 第一段全部小于 `a`；
- 第二段全部在 `[a, b]` 内；
- 第三段全部大于 `b`。

三段均可为空。求最少相邻交换次数，答案对 $10^9+7$ 取模。

- $1\le |nums|\le10^5$；
- $1\le nums_i,a,b\le10^9$。

**解题思路**

元素的具体值不再重要，只需要分为三类：

```text
L: x < a
M: a <= x <= b
H: x > b
```

目标形态就是：

```text
L L ... L M M ... M H H ... H
```

令三类的顺序分别为 `0, 1, 2`。将一个序列通过相邻交换变为非降序，最少交换次数恰好等于逆序对数量：每个逆序对中的两个元素最终必须交换相对顺序，而一次相邻交换只会改变这一对相邻元素的相对顺序；不断交换相邻逆序对又能恰好每次消去一个逆序对。

从左向右扫描，维护此前出现的 `M`、`H` 数量：

- 当前为 `L`：前面每个 `M`、`H` 都与它构成逆序；
- 当前为 `M`：前面每个 `H` 都与它构成逆序；
- 当前为 `H`：不会形成以它为右端点的逆序。

**代码**

```cpp
class Solution {
public:
    int minAdjacentSwaps(vector<int>& nums, int a, int b) {
        static constexpr long long MOD = 1000000007LL;
        long long middle = 0;
        long long high = 0;
        long long ans = 0;

        for (int x : nums) {
            if (x < a) {
                ans += middle + high;
            } else if (x <= b) {
                ans += high;
                middle++;
            } else {
                high++;
            }
        }

        return static_cast<int>(ans % MOD);
    }
};
```

**复杂度分析**

时间复杂度：$O(|nums|)$。

空间复杂度：$O(1)$。

**变形**

若类别数量扩展为 `k` 类，仍然是在统计类别数组的逆序对。`k` 较小时可以维护每一类的计数；`k` 很大时可使用树状数组，在 $O(n\log k)$ 时间内完成统计。

## 3993 - Minimum Cost to Convert String III

**题意**

题目链接：[Minimum Cost to Convert String III](https://leetcode.com/problems/minimum-cost-to-convert-string-iii/description/)

给定等长字符串 `source`、`target`，以及若干规则 `pattern -> replacement`。两端长度相同；`pattern` 中的 `*` 能匹配任意一个字符，`replacement` 不含通配符。一次应用规则的成本为基础成本加上 `pattern` 中 `*` 的数量。

每次规则应用后，其覆盖的所有位置都不能再被任何规则使用。求把 `source` 转成 `target` 的最小成本；无解时返回 `-1`。

- $1\le |source|=|target|\le5000$；
- 规则数不超过 $200$；
- 每条规则长度不超过 $20$，且至多有 $5$ 个 `*`。

**解题思路**

一个位置至多参与一次规则，因此不同规则覆盖的区间一定不相交。某个区间在被规则覆盖前从未被修改过，匹配对象始终是 `source` 的原始子串；被覆盖后又不能再修改，所以 `replacement` 必须直接等于 `target` 的对应子串。

于是可以从左向右进行前缀 DP。定义 `dp[i]` 为已经将前 `i` 个位置变为目标字符串的最小成本。

从 `dp[i]` 有两类转移：

1. 若 `source[i] == target[i]`，不使用规则，转移到 `dp[i + 1]`，费用为 `0`；
2. 枚举每条长度为 `len` 的规则。若其 `pattern` 能匹配 `source[i..i + len - 1]`，且 `replacement` 等于 `target[i..i + len - 1]`，则转移到 `dp[i + len]`。

DP 按下标递增进行，规则转移直接跨过一个完整区间，因此天然保证所有规则区间互不重叠。

**代码**

```cpp
class Solution {
public:
    int minCost(string source, string target,
                vector<vector<string>>& rules, vector<int>& costs) {
        const int n = source.size();
        const int r = rules.size();
        const int INF = 1e9;

        vector<int> length(r);
        vector<int> cost(r);

        for (int j = 0; j < r; j++) {
            length[j] = rules[j][0].size();
            cost[j] = costs[j];

            for (char c : rules[j][0]) {
                cost[j] += (c == '*');
            }
        }

        vector<int> dp(n + 1, INF);
        dp[0] = 0;

        for (int i = 0; i < n; i++) {
            if (dp[i] == INF) {
                continue;
            }

            if (source[i] == target[i]) {
                dp[i + 1] = min(dp[i + 1], dp[i]);
            }

            for (int j = 0; j < r; j++) {
                int len = length[j];
                if (i + len > n) {
                    continue;
                }

                const string& pattern = rules[j][0];
                const string& replacement = rules[j][1];
                bool ok = true;

                for (int k = 0; k < len; k++) {
                    if (pattern[k] != '*' && pattern[k] != source[i + k]) {
                        ok = false;
                        break;
                    }
                    if (replacement[k] != target[i + k]) {
                        ok = false;
                        break;
                    }
                }

                if (ok) {
                    dp[i + len] = min(dp[i + len], dp[i] + cost[j]);
                }
            }
        }

        return dp[n] == INF ? -1 : dp[n];
    }
};
```

**复杂度分析**

设字符串长度为 $n$、规则数为 $r$、最大规则长度为 $L$。每个位置枚举所有规则并检查至多 $L$ 个字符。

时间复杂度：$O(nrL)$。本题最大约为 $5000\times200\times20=2\times10^7$ 次字符比较。

空间复杂度：$O(n+r)$。

**变形**

若允许同一位置被多条规则重复使用，规则之间会形成状态转换，不能再把每个区间视为一次性完成；此时通常需要按字符串片段建立最短路或区间 DP，而不是本题的线性前缀 DP。
