## 3968 - Maximum Manhattan Distance After All Moves

**题意**

题目链接：[Maximum Manhattan Distance After All Moves](https://leetcode.com/problems/maximum-manhattan-distance-after-all-moves/description/)

给定一个字符串 `moves`，从原点 `(0, 0)` 出发执行所有移动：

- `U`：向上移动一格；
- `D`：向下移动一格；
- `L`：向左移动一格；
- `R`：向右移动一格；
- `_`：可以独立替换成任意一种方向。

求所有替换方案中，最终位置到原点的最大曼哈顿距离。

- `1 <= moves.length <= 10^5`

**解题思路**

设固定移动产生的净位移为 `(x, y)`，下划线的数量为 `cnt`。如果忽略下划线，最终曼哈顿距离为：

$$
|x|+|y|
$$

对于任意固定的符号组合 `sx, sy`，其中 `sx, sy` 均为 `1` 或 `-1`，有：

$$
|x|+|y|=\max_{sx,sy\in\{-1,1\}}(sx\cdot x+sy\cdot y)
$$

固定一组符号后，每个下划线都可以选择对应的横向或纵向方向，使它对该表达式贡献 `1`。因此 `cnt` 个下划线总能额外贡献 `cnt`。

答案就是：

$$
|x|+|y|+cnt
$$

代码中直接统计固定移动的净位移和下划线数量即可。

**正确性说明**

曼哈顿距离可以表示成四种符号组合下的线性函数最大值。对其中取得最大值的一组符号，每个下划线都能选择使线性函数增加 `1` 的方向，因此每个下划线都能贡献一个单位距离；固定移动的贡献由最终净位移决定。故上述公式得到的就是最大曼哈顿距离。

**代码**

```cpp
class Solution {
public:
    int maxDistance(string moves) {
        int x = 0;
        int y = 0;
        int cnt = 0;

        for (char c : moves) {
            if (c == 'U') {
                ++y;
            } else if (c == 'D') {
                --y;
            } else if (c == 'L') {
                --x;
            } else if (c == 'R') {
                ++x;
            } else {
                ++cnt;
            }
        }

        return abs(x) + abs(y) + cnt;
    }
};
```

**复杂度分析**

设 `n = moves.length`。

时间复杂度：$O(n)$。

空间复杂度：$O(1)$。

**变形**

如果每个通配符只能在部分方向中选择，可以对四组符号分别计算每个通配符能否贡献 `1`，再取四组结果的最大值。

## 3969 - Valid Subarrays With Matching Sum Digits I

**题意**

题目链接：[Valid Subarrays With Matching Sum Digits I](https://leetcode.com/problems/valid-subarrays-with-matching-sum-digits-i/description/)

给定正整数数组 `nums` 和数字 `x`。若连续子数组 `nums[l..r]` 的元素和满足：

- 十进制首位等于 `x`；
- 十进制末位等于 `x`；

则称该子数组合法。返回合法子数组的数量。

- `1 <= nums.length <= 1500`
- `1 <= nums[i] <= 10^9`
- `1 <= x <= 9`

**解题思路**

数组长度只有 `1500`，可以枚举所有子数组。固定左端点 `l` 后，从左向右扩展右端点 `r`，并增量维护当前子数组和：

$$
sum=sum+nums[r]
$$

这样每个子数组的和都可以在 $O(1)$ 时间内得到。

### 1. 判断末位

一个正整数的十进制末位为：

$$
sum\bmod 10
$$

因此末位等于 `x` 的条件为 `sum % 10 == x`。

### 2. 判断首位

不断进行整数除法 `sum /= 10`，直到 `sum < 10`，此时剩下的数字就是原数的十进制首位。

由于数组元素为正数，子数组和始终为正数，不需要额外处理 `0` 的情况。

**代码**

```cpp
class Solution {
public:
    int countValidSubarrays(vector<int>& nums, int x) {
        int n = nums.size();
        int ans = 0;

        for (int l = 0; l < n; l++) {
            long long sum = 0;

            for (int r = l; r < n; r++) {
                sum += nums[r];

                if (sum % 10 != x) {
                    continue;
                }

                long long first = sum;
                while (first >= 10) {
                    first /= 10;
                }

                if (first == x) {
                    ++ans;
                }
            }
        }

        return ans;
    }
};
```

**复杂度分析**

设所有子数组和的十进制位数最多为 `D`。枚举子数组需要 $O(n^2)$，每次判断首位需要 $O(D)$。

时间复杂度：$O(n^2D)$。在本题约束下 `D` 不超过 `13`，可以视为 $O(n^2)$。

空间复杂度：$O(1)$。

### 扩展一：数组元素仍为正数，但扩大 `n` 的范围

如果仍然满足 `nums[i] > 0`，但将 `n` 扩大到 $10^5$，就不能再枚举所有子数组。此时利用前缀和的单调性，可以把复杂度降到 $O(n\log S)$。

设：

$$
pre_0=0,\qquad pre_j=\sum_{i=0}^{j-1}nums[i]
$$

子数组 `nums[l..r]` 的和为：

$$
sum=pre_{r+1}-pre_l
$$

因为所有 `nums[i]` 都是正数，所以 `pre` 严格递增。

#### 1. 将最高位转化为若干区间

令 `p = 10^k`。所有最高位为 `x`、数量级为 `p` 的正整数都位于：

$$
[L,R]=[x\cdot p,(x+1)\cdot p-1]
$$

例如 `x = 3` 时，区间依次为：

$$
[3,3],[30,39],[300,399],\ldots
$$

这些区间互不相交，枚举所有区间即可覆盖所有首位为 `x` 的正整数。

#### 2. 将子数组条件转化为前缀和窗口

固定右端前缀和 `s = pre[j]`。若子数组和位于 `[L,R]`，则：

$$
L\le s-pre_i\le R
$$

移项后得到：

$$
s-R\le pre_i\le s-L
$$

因此只需要统计历史前缀和落在窗口 `[s-R, s-L]` 中的数量。

最低位为 `x` 的条件为：

$$
s-pre_i\equiv x\pmod {10}
$$

即：

$$
pre_i\bmod10=(s-x)\bmod10
$$

#### 3. 使用双指针维护窗口

由于 `pre` 严格递增，随着 `j` 增大，窗口的左右边界也都单调增大。因此对于每个最高位区间，可以使用两个指针维护：

- `right`：把所有不超过窗口右边界的前缀和加入窗口；
- `left`：删除所有小于窗口左边界的前缀和。

窗口中只保存满足：

$$
s-R\le pre_i\le s-L
$$

的历史前缀和。再用 `cnt[10]` 统计窗口内各个模 `10` 的数量，就能在 $O(1)$ 时间内完成最低位条件的查询。

处理 `pre[j]` 时，先查询，再把它加入后续窗口，从而保证 `i < j`。

**扩大 `n` 后的代码**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    long long countValidSubarrays(vector<int>& nums, int x) {
        int n = nums.size();
        vector<long long> pre(n + 1, 0);

        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i];
        }

        long long total = pre[n];
        long long ans = 0;

        for (long long p = 1; p <= total / x; ) {
            long long leftValue = 1LL * x * p;
            long long rightValue = 1LL * (x + 1) * p - 1;

            vector<int> cnt(10, 0);
            int left = 0;
            int right = 0;

            for (int j = 1; j <= n; j++) {
                long long low = pre[j] - rightValue;
                long long high = pre[j] - leftValue;

                while (right < j && pre[right] <= high) {
                    ++cnt[pre[right] % 10];
                    ++right;
                }

                while (left < right && pre[left] < low) {
                    --cnt[pre[left] % 10];
                    ++left;
                }

                int target = static_cast<int>((pre[j] % 10 - x + 10) % 10);
                ans += cnt[target];
            }

            if (p > total / 10) {
                break;
            }
            p *= 10;
        }

        return ans;
    }
};
```

**扩大 `n` 后的复杂度分析**

设所有元素之和为：

$$
S=\sum nums_i
$$

需要枚举的最高位区间数量为 $O(\log_{10}S)$。对于每个区间，两个指针都只向右移动，每个前缀和最多加入和删除一次，因此复杂度为 $O(n)$。

时间复杂度：$O(n\log S)$。

空间复杂度：$O(n)$，主要用于保存前缀和。

### 扩展二：允许数组中出现负数

如果在扩大 `n` 的基础上进一步允许 `nums` 中出现负数，并将负数的首位、末位按照绝对值判断，那么前缀和不再单调，扩展一中的双指针也就不能使用。

这时可以使用前缀和、最高位区间、模 `10` 分类和树状数组，将问题优化到 $O(n\log V\log n)$。

#### 1. 负数的判断规则

对负数和 `sum`，按照 $|sum|$ 判断首位和末位。例如：

- `sum = -121` 时，按照 `121` 判断，首位和末位都是 `1`；
- `sum = 0` 不合法，因为 `x` 的范围是 `1` 到 `9`。

设前缀和为：

$$
pre_0=0,\qquad pre_j=\sum_{i=0}^{j-1}nums[i]
$$

子数组 `nums[i..j-1]` 的和为：

$$
d=pre_j-pre_i
$$

当数组中允许负数时，前缀和不再单调，因此不能继续用双指针维护数值区间。需要在枚举右端点 `j` 时，查询历史前缀和 `pre_i`。

#### 2. 最高位转化为区间

设：

$$
p=10^k
$$

一个正数的首位为 `x`，且数量级为 `p` 时，它位于区间：

$$
[L,R]=[x\cdot p,(x+1)\cdot p-1]
$$

例如 `x = 2` 时，可能的区间为：

$$
[2,2],[20,29],[200,299],\ldots
$$

因此需要枚举所有不超过前缀和差值范围的 `p`。

#### 3. 统计正数子数组和

当前右端前缀和为 `s = pre[j]`，历史前缀和为 `q = pre[i]`。

若子数组和为正数，并且首位位于 `[L,R]`，则：

$$
L\le s-q\le R
$$

移项后得到：

$$
s-R\le q\le s-L
$$

末位为 `x` 的条件是：

$$
s-q\equiv x\pmod {10}
$$

所以历史前缀和必须满足：

$$
q\in[s-R,s-L],\qquad q\bmod10=(s-x)\bmod10
$$

#### 4. 统计负数子数组和

若子数组和为负数，并且绝对值位于 `[L,R]`，则：

$$
-R\le s-q\le-L
$$

移项后得到：

$$
s+L\le q\le s+R
$$

由于按照绝对值判断末位，要求：

$$
|s-q|\equiv x\pmod {10}
$$

负数满足 `s - q ≡ -x (mod 10)`，因此：

$$
q\bmod10=(s+x)\bmod10
$$

也就是说，负数部分需要查询：

$$
q\in[s+L,s+R],\qquad q\bmod10=(s+x)\bmod10
$$

#### 5. 10 棵树状数组

查询同时受到两个条件限制：

1. 前缀和值位于某个数值区间；
2. 前缀和模 `10` 等于指定值。

因此建立 `bit[0..9]` 十棵树状数组，其中 `bit[t]` 只保存模 `10` 等于 `t` 的历史前缀和。由于前缀和值可能为负数，需要先对所有前缀和做坐标压缩。

对于查询：

$$
q\in[a,b],\qquad q\bmod10=t
$$

在 `bit[t]` 中使用两次前缀和查询即可得到区间数量：

$$
count(q\le b)-count(q<a)
$$

#### 6. 枚举顺序

依次枚举右端点 `j`。处理 `pre[j]` 时，树状数组中只能包含：

$$
pre_0,pre_1,\ldots,pre_{j-1}
$$

这样天然保证子数组左端点早于右端点。具体顺序是：

1. 初始插入 `pre[0]`；
2. 查询当前 `pre[j]` 对应的所有正数、负数区间；
3. 查询结束后再插入 `pre[j]`。

如果提前插入当前前缀和，就可能把长度为 `0` 的区间错误地统计进去。

**扩展二代码**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    using LL = long long;

    struct BIT {
        int n;
        vector<int> tree;

        BIT(int n = 0) : n(n), tree(n + 1, 0) {}

        void add(int x, int value) {
            for (; x <= n; x += x & -x) {
                tree[x] += value;
            }
        }

        int query(int x) const {
            int ans = 0;
            for (; x > 0; x -= x & -x) {
                ans += tree[x];
            }
            return ans;
        }
    };

    int mod10(LL value) {
        return static_cast<int>((value % 10 + 10) % 10);
    }

    int queryRange(const BIT& bit, const vector<LL>& values,
                   LL left, LL right) {
        if (left > right) {
            return 0;
        }

        int l = lower_bound(values.begin(), values.end(), left)
                - values.begin();
        int r = upper_bound(values.begin(), values.end(), right)
                - values.begin();

        return bit.query(r) - bit.query(l);
    }

public:
    long long countValidSubarrays(vector<int>& nums, int x) {
        int n = nums.size();
        vector<LL> prefix(n + 1, 0);

        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        LL mn = *min_element(prefix.begin(), prefix.end());
        LL mx = *max_element(prefix.begin(), prefix.end());
        LL limit = mx - mn;

        vector<LL> values = prefix;
        sort(values.begin(), values.end());
        values.erase(unique(values.begin(), values.end()), values.end());

        int m = values.size();
        vector<BIT> bits;
        for (int i = 0; i < 10; i++) {
            bits.emplace_back(m);
        }

        auto insert = [&](LL value) {
            int id = lower_bound(values.begin(), values.end(), value)
                     - values.begin() + 1;
            bits[mod10(value)].add(id, 1);
        };

        LL ans = 0;
        insert(prefix[0]);

        for (int j = 1; j <= n; j++) {
            LL s = prefix[j];

            for (LL p = 1; p <= limit / x; ) {
                LL left = 1LL * x * p;
                LL right = 1LL * (x + 1) * p - 1;

                // 正数子数组和位于 [left, right]
                int positiveMod = mod10(s - x);
                ans += queryRange(bits[positiveMod], values,
                                  s - right, s - left);

                // 负数子数组和位于 [-right, -left]
                int negativeMod = mod10(s + x);
                ans += queryRange(bits[negativeMod], values,
                                  s + left, s + right);

                if (p > limit / 10) {
                    break;
                }
                p *= 10;
            }

            insert(s);
        }

        return ans;
    }
};
```

**扩展二复杂度分析**

设：

$$
V=\max(pre)-\min(pre)
$$

需要枚举的十进制数量级为 $O(\log_{10}V)$。每个右端点进行常数次树状数组区间查询，每次查询复杂度为 $O(\log n)$。

时间复杂度：$O(n\log V\log n)$。

空间复杂度：$O(n)$。

如果扩展题只允许统计正数子数组和，可以删除负数区间对应的第二次 `queryRange` 查询。

## 3970 - Shortest Path With At Most K Consecutive Identical Characters

**题意**

题目链接：[Shortest Path With At Most K Consecutive Identical Characters](https://leetcode.com/problems/shortest-path-with-at-most-k-consecutive-identical-characters/description/)

给定一个带权无向图，节点编号为 `0` 到 `n - 1`。节点 `i` 的标签为 `labels[i]`，每条边为 `[u, v, w]`，表示连接 `u` 和 `v`、边权为 `w`。

从节点 `0` 到节点 `n - 1` 的路径对应一个标签字符串，即路径上依次经过的节点标签。要求该字符串中连续相同字符的最长长度不超过 `k`，求满足条件的最短路径长度；如果不存在合法路径，返回 `-1`。

- `1 <= n == labels.length <= 5 * 10^4`
- `0 <= edges.length <= 5 * 10^4`
- `1 <= w_i <= 10^4`
- `1 <= k <= 50`

**解题思路**

普通 Dijkstra 只记录当前节点是不够的。因为从同一个节点继续走时，后续路径是否合法还取决于：当前节点的标签已经连续出现了多少次。

因此把状态扩展为：

$$
(u,c)
$$

其中：

- `u`：当前所在节点；
- `c`：路径末尾连续出现 `labels[u]` 的次数。

令 `dist[u][c]` 表示到达状态 `(u, c)` 的最短距离。

### 1. 状态转移

从 `(u, c)` 走到相邻节点 `v`：

- 如果 `labels[u] == labels[v]`，新的连续长度为 `c + 1`；
- 否则连续段被打断，新的连续长度为 `1`。

若新的连续长度不超过 `k`，就可以进行转移：

$$
dist[v][nc]=\min(dist[v][nc],dist[u][c]+w)
$$

初始状态为 `(0, 1)`，因为路径一开始已经包含节点 `0` 的标签。

### 2. 使用 Dijkstra

状态图中的每条边权仍然是原图的正权边，因此可以直接在状态图上运行 Dijkstra。最终答案是所有 `dist[n - 1][c]` 的最小值。

**正确性证明**

引理 1：状态 `(u, c)` 包含了判断后续路径是否合法所需的全部信息。

从当前节点继续添加一个节点时，新的连续相同字符长度只取决于当前节点的标签和当前连续长度 `c`，与更早的路径内容无关。因此 `(u, c)` 足以决定所有后续转移是否合法。

引理 2：状态转移与合法路径扩展一一对应。

沿原图的一条边从 `u` 走到 `v` 时，根据两个节点标签是否相同，转移后的连续长度恰好为 `c + 1` 或 `1`。只有长度不超过 `k` 时才加入状态图，所以状态图中的每条路径都对应一条合法原图路径；反过来，每条合法原图路径都能按照相同规则生成状态图路径。

定理：Dijkstra 返回的答案是最短合法路径长度。

由于状态图中的边权为正，Dijkstra 能求出每个状态的最短距离。状态图中所有以 `n - 1` 为节点部分的状态，恰好对应所有合法到达终点的原图路径，因此取这些状态的最小距离即可得到正确答案。

**代码**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int shortestPath(int n, vector<vector<int>>& edges,
                     string labels, int k) {
        vector<vector<pair<int, int>>> graph(n);

        for (auto& e : edges) {
            int u = e[0];
            int v = e[1];
            int w = e[2];
            graph[u].push_back({v, w});
            graph[v].push_back({u, w});
        }

        const long long INF = (1LL << 60);
        vector<vector<long long>> dist(n, vector<long long>(k + 1, INF));

        using State = tuple<long long, int, int>;
        priority_queue<State, vector<State>, greater<State>> pq;

        dist[0][1] = 0;
        pq.push({0, 0, 1});

        while (!pq.empty()) {
            auto [d, u, c] = pq.top();
            pq.pop();

            if (d != dist[u][c]) {
                continue;
            }

            for (auto [v, w] : graph[u]) {
                int nc = (labels[u] == labels[v]) ? c + 1 : 1;
                if (nc > k) {
                    continue;
                }

                long long nd = d + w;
                if (nd < dist[v][nc]) {
                    dist[v][nc] = nd;
                    pq.push({nd, v, nc});
                }
            }
        }

        long long ans = INF;
        for (int c = 1; c <= k; c++) {
            ans = min(ans, dist[n - 1][c]);
        }

        return ans == INF ? -1 : static_cast<int>(ans);
    }
};
```

**复杂度分析**

状态数为 $O(nk)$，状态转移数为 $O(|E|k)$。

时间复杂度：$O((nk+|E|k)\log(nk))$。

空间复杂度：$O(nk+|E|)$。

**变形**

如果限制的是最近 `k` 个节点标签组成的模式，就不能只记录连续长度，需要把状态扩展为长度为 `k` 的后缀；如果限制条件可以由有限自动机表示，也可以将图节点和自动机状态做笛卡尔积后继续使用最短路算法。

## 3971 - Maximum Total Value

**题意**

题目链接：[Maximum Total Value](https://leetcode.com/problems/maximum-total-value/description/)

给定两个数组 `value` 和 `decay`。第 `i` 个下标的初始收益为 `value[i]`，每选择一次该下标，它之后的收益都会减少 `decay[i]`。

如果第 `t` 次选择下标 `i`（从 `t = 0` 开始），获得的收益为：

$$
value[i]-t\cdot decay[i]
$$

每个下标可以选择任意次，但总选择次数不超过 `m`。求能够获得的最大总收益，答案对 $10^9+7$ 取模。

- `1 <= value.length == decay.length <= 10^5`
- `1 <= value[i], decay[i] <= 10^9`
- `1 <= m <= 10^9`

**解题思路**

### 1. 每个下标对应一个等差收益序列

下标 `i` 产生的收益序列为：

$$
value[i],\quad value[i]-decay[i],\quad value[i]-2decay[i],\ldots
$$

同一个序列中的收益单调不增。由于总选择次数是“至多” `m`，任何非正收益都不应该选择。因此问题等价于：从所有序列中的正数里选择最大的 `m` 个收益。

为什么可以忽略“同一个下标必须按顺序选择”的限制？因为每个序列单调不增。如果选择了某个序列的第 `t` 个收益，那么它之前的 `t` 个收益都不小于它；把它们一起选入最优的前 `m` 个收益即可，所以全局取前 `m` 个正收益天然满足前缀限制。

### 2. 二分第 `m` 大收益

定义：

$$
count(h)=\text{所有收益中不小于 }h\text{ 的收益数量}
$$

对于一个下标 `i`，满足：

$$
value[i]-t\cdot decay[i]\ge h
$$

的非负整数 `t` 个数为：

$$
cnt_i=\max\left(0,\left\lfloor\frac{value[i]-h}{decay[i]}\right\rfloor+1\right)
$$

因此可以在 $O(n)$ 时间内计算 `count(h)`。随着 `h` 增大，`count(h)` 单调不增，可以二分最大的 `h`，使得 `count(h) >= m`。这个 `h` 就是第 `m` 大正收益。

如果正收益总数不足 `m`，则直接选择所有正收益。

### 3. 计算阈值以上的收益总和

二分得到阈值 `h` 后，先计算所有严格大于 `h` 的收益之和，设数量为 `cnt`、总和为 `sum`。每个序列中严格大于 `h` 的前 `cnt_i` 项构成等差数列，其和为：

$$
cnt_i\cdot value[i]
-decay[i]\cdot\frac{cnt_i(cnt_i-1)}2
$$

剩余还需要选择 `m - cnt` 个收益，它们全部等于 `h`。最终答案为：

$$
sum+(m-cnt)\cdot h
$$

计算数量时可以把总数限制在 `m`，避免无意义的大数累加；等差数列求和使用 `__int128`，避免中间乘法溢出。

**正确性证明**

引理 1：最优方案不会选择非正收益。

题目允许少于 `m` 次选择。删除任意非正收益不会减少总收益，因此存在一个最优方案只包含正收益。

引理 2：问题等价于选择所有正收益中的前 `m` 大值。

每个下标的收益序列单调不增。若一个方案选择了某个序列的后续收益，则该序列之前的收益都更大或相等，可以替换为这些前置收益而不降低总和。因此选出的全局前 `m` 个正收益可以调整为每个序列的前缀，满足原题的选择顺序限制。

引理 3：二分得到的 `h` 是第 `m` 大收益。

`count(h)` 随 `h` 增大单调不增。二分找到最大的满足 `count(h) >= m` 的阈值后，至少有 `m` 个收益不小于 `h`，而大于 `h` 的收益数量少于 `m`，所以第 `m` 大收益恰好为 `h`。

定理：算法返回最大总收益。

算法先完整加入所有大于 `h` 的收益，再补入若干个等于 `h` 的收益，恰好得到前 `m` 大收益；若正收益不足 `m`，则加入全部正收益。根据前两个引理，这正是原问题的最优选择，因此算法正确。

**代码**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    using i128 = __int128_t;
    static constexpr long long MOD = 1000000007LL;

    long long countAtLeast(const vector<int>& value,
                           const vector<int>& decay,
                           long long h, long long limit) {
        long long total = 0;

        for (int i = 0; i < static_cast<int>(value.size()); i++) {
            if (value[i] < h) {
                continue;
            }

            long long cnt = (value[i] - h) / decay[i] + 1;
            total += cnt;
            if (total >= limit) {
                return limit;
            }
        }

        return total;
    }

    long long sumAtLeast(const vector<int>& value,
                         const vector<int>& decay,
                         long long h) {
        i128 total = 0;

        for (int i = 0; i < static_cast<int>(value.size()); i++) {
            if (value[i] < h) {
                continue;
            }

            long long cnt = (value[i] - h) / decay[i] + 1;
            total += static_cast<i128>(cnt) * value[i];
            total -= static_cast<i128>(decay[i]) * cnt * (cnt - 1) / 2;
        }

        return static_cast<long long>(total);
    }

    pair<long long, long long> sumGreater(const vector<int>& value,
                                          const vector<int>& decay,
                                          long long h) {
        long long cntAll = 0;
        i128 sumAll = 0;

        for (int i = 0; i < static_cast<int>(value.size()); i++) {
            if (value[i] <= h) {
                continue;
            }

            long long cnt = (value[i] - h - 1) / decay[i] + 1;
            cntAll += cnt;
            sumAll += static_cast<i128>(cnt) * value[i];
            sumAll -= static_cast<i128>(decay[i]) * cnt * (cnt - 1) / 2;
        }

        return {cntAll, static_cast<long long>(sumAll)};
    }

public:
    int maxTotalValue(vector<int>& value, vector<int>& decay, int m) {
        long long need = m;
        long long positive = countAtLeast(value, decay, 1, need + 1);

        if (positive <= need) {
            return sumAtLeast(value, decay, 1) % MOD;
        }

        long long lo = 1;
        long long hi = *max_element(value.begin(), value.end());

        while (lo < hi) {
            long long mid = (lo + hi + 1) / 2;
            if (countAtLeast(value, decay, mid, need) >= need) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }

        long long h = lo;
        auto [cnt, sum] = sumGreater(value, decay, h);

        long long ans = (sum % MOD +
                         (need - cnt) % MOD * (h % MOD)) % MOD;
        return static_cast<int>(ans);
    }
};
```

**复杂度分析**

设 `n = value.length`，`V = max(value)`。每次计算收益数量需要 $O(n)$，二分阈值需要 $O(\log V)$ 次计算。

时间复杂度：$O(n\log V)$。

空间复杂度：$O(1)$，不计输入数组。

**变形**

这类问题的共同形式是：每个对象产生一个单调收益序列，要求取收益最大的前 `m` 项。若收益可以被 $O(1)$ 计算并且能够统计“不小于阈值”的项数，就可以使用同样的阈值二分与补齐方法。

## 知识点总结

本场比赛的四道题分别对应了几种常见的竞赛模型：

1. **曼哈顿距离的符号表示**：把绝对值转化为有限个线性函数的最大值；
2. **双重枚举与增量维护**：固定左端点后维护子数组和；
3. **状态扩展最短路**：把影响后续可行性的历史信息加入 Dijkstra 状态；
4. **单调收益序列与阈值二分**：把重复选择问题转化为选取全局前 `m` 大收益。
