## 3974 - Maximum Total Sum of K Selected Elements

**题意**

题目链接：[Maximum Total Sum of K Selected Elements](https://leetcode.com/problems/maximum-total-sum-of-k-selected-elements/description/)

给定正整数数组 `nums`，以及整数 `k` 和 `mul`。需要恰好选择 `k` 个元素，并按照任意顺序依次处理。

处理一个元素时，可以选择：

- 直接将元素值加入答案；
- 将元素值乘以当前的 `mul` 后加入答案。

每处理一个元素，当前的 `mul` 都减 `1`，即使当前选择的是直接加法。求能够得到的最大总和。

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`
- `1 <= mul <= 10^5`

**解题思路**

### 1. 将操作转化为位置系数

假设处理第 `i` 个元素时，当前乘数为：

$$
mul-i
$$

对于元素 `x`，两种操作的贡献分别为：

$$
x,\qquad x(mul-i)
$$

由于 `x` 是正数，最优贡献为：

$$
x\cdot\max(1,mul-i)
$$

所以第 `i` 个处理位置对应的实际系数为：

$$
w_i=\max(1,mul-i)
$$

系数序列单调不增。例如 `mul = 4` 时，前几个系数为：

$$
4,3,2,1,1,1,\ldots
$$

### 2. 选择最大的 `k` 个元素

所有系数都至少为 `1`。如果一个方案选择了较小元素 `a`，却没有选择更大的元素 `b`，其中 `b > a`，把 `a` 替换为 `b` 后，答案至少增加：

$$
(b-a)w>0
$$

因此最优方案一定选择 `nums` 中最大的 `k` 个元素。

### 3. 最大元素匹配最大系数

设 `a >= b`，`p >= q`。比较两种匹配：

$$
ap+bq\qquad\text{和}\qquad aq+bp
$$

前者减去后者为：

$$
ap+bq-aq-bp=(a-b)(p-q)\ge0
$$

因此较大的元素应该匹配较大的系数。将最大的 `k` 个元素按降序排列后，依次乘以：

$$
\max(1,mul),\max(1,mul-1),\ldots,\max(1,mul-k+1)
$$

即可得到答案。

**代码**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    long long maxSum(vector<int>& nums, int k, int mul) {
        sort(nums.rbegin(), nums.rend());

        long long ans = 0;

        for (int i = 0; i < k; i++) {
            long long coefficient = max(1LL, 1LL * mul - i);
            ans += 1LL * nums[i] * coefficient;
        }

        return ans;
    }
};
```

**正确性证明**

第 `i` 个位置的最优贡献系数为 `max(1, mul - i)`，这是由两种操作直接比较得到的。

由于所有系数均为正数，用更大的元素替换更小的元素不会降低答案，所以最优方案选择最大的 `k` 个元素。

最后，根据交换不等式：

$$
ap+bq-(aq+bp)=(a-b)(p-q)\ge0
$$

较大的元素匹配较大的系数不会更差。因此代码中的排序和匹配方式达到最大总和。

**复杂度分析**

设 `n = nums.length`。

时间复杂度：$O(n\log n)$。

空间复杂度：$O(\log n)$，主要是排序递归栈；不计输入数组本身。

### 变形：使用 `nth_element` 优化

如果只关心最大的 `k` 个元素，可以先使用 `nth_element` 将最大的 `k` 个元素放到数组前缀，再只对这 `k` 个元素排序。

- `nth_element` 的平均复杂度为 $O(n)$；
- 排序前 `k` 个元素需要 $O(k\log k)$；
- 计算答案需要 $O(k)$。

总复杂度为：

$$
O(n+k\log k)
$$

代码如下：

```cpp
class Solution {
public:
    long long maxSum(vector<int>& nums, int k, int mul) {
        int n = nums.size();

        if (k < n) {
            nth_element(nums.begin(), nums.begin() + k - 1,
                        nums.end(), greater<int>());
        }

        sort(nums.begin(), nums.begin() + k, greater<int>());

        long long ans = 0;
        for (int i = 0; i < k; i++) {
            long long coefficient = max(1LL, 1LL * mul - i);
            ans += 1LL * nums[i] * coefficient;
        }

        return ans;
    }
};
```

当 `k` 很小时，这种写法可以避免对没有被选择的元素进行完整排序。

## 3975 - Filter Occupied Intervals

**题意**

题目链接：[Filter Occupied Intervals](https://leetcode.com/problems/filter-occupied-intervals/description/)

给定若干闭区间 `occupiedIntervals[i] = [start_i, end_i]`，表示被占用的整数时间点。区间可能重叠。

另外给定闭区间 `[freeStart, freeEnd]`，需要执行：

1. 合并所有重叠或相邻的占用区间；
2. 从合并后的占用区间中删除免费区间包含的所有整数点。

返回剩余的占用区间，要求按顺序排列、互不重叠，并且区间数量最少。

本题中的相邻区间也需要合并，例如 `[1,1]` 和 `[2,2]` 应合并为 `[1,2]`。

- `1 <= occupiedIntervals.length <= 5 * 10^4`
- `1 <= start_i <= end_i <= 10^9`
- `1 <= freeStart <= freeEnd <= 10^9`

**解题思路**

算法分为两步：先合并占用区间，再从每个合并区间中删除免费区间。

### 1. 合并重叠或相邻区间

按照左端点排序。设当前已经合并出的最后一个区间为 `[l,r]`，下一个区间为 `[x,y]`。

如果：

$$
x\le r+1
$$

则两个区间重叠或相邻，可以合并为：

$$
[l,\max(r,y)]
$$

否则两者之间至少有一个未占用的整数点，需要新建区间。

### 2. 删除免费区间

对于合并后的区间 `[l,r]` 和免费区间 `[s,e]`：

- 如果两者不相交，保留 `[l,r]`；
- 如果 `l < s`，保留左侧 `[l,s-1]`；
- 如果 `r > e`，保留右侧 `[e+1,r]`。

例如：

```text
占用区间：[2,10]
免费区间：[5,7]
```

删除后得到 `[2,4]` 和 `[8,10]`。

**代码**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<vector<int>> filterOccupiedIntervals(
        vector<vector<int>>& occupiedIntervals,
        int freeStart,
        int freeEnd
    ) {
        sort(occupiedIntervals.begin(), occupiedIntervals.end());

        vector<vector<int>> merged;

        for (const auto& interval : occupiedIntervals) {
            int l = interval[0];
            int r = interval[1];

            if (merged.empty() ||
                1LL * l > 1LL * merged.back()[1] + 1) {
                merged.push_back({l, r});
            } else {
                merged.back()[1] = max(merged.back()[1], r);
            }
        }

        vector<vector<int>> ans;

        for (const auto& interval : merged) {
            int l = interval[0];
            int r = interval[1];

            if (r < freeStart || l > freeEnd) {
                ans.push_back({l, r});
                continue;
            }

            if (l < freeStart) {
                ans.push_back({l, freeStart - 1});
            }

            if (r > freeEnd) {
                ans.push_back({freeEnd + 1, r});
            }
        }

        return ans;
    }
};
```

**正确性证明**

排序后依次处理区间。对于相邻的两个区间，如果左区间的右端点加 `1` 不小于右区间的左端点，它们覆盖的整数点集合可以由一个闭区间表示，合并不会改变占用点集合；否则中间存在未占用整数点，不能合并。因此第一步得到的区间恰好表示全部原始占用点。

对于每个合并区间，删除免费区间后，剩余点只能位于免费区间左侧或右侧。代码分别加入 `[l, freeStart - 1]` 和 `[freeEnd + 1, r]`，恰好保留所有未被删除的点。

合并结束后，任意两个结果区间之间至少有一个未占用整数点，所以它们不能继续合并，区间数量已经最少。

**复杂度分析**

设占用区间数量为 `n`。

时间复杂度：$O(n\log n)$。

空间复杂度：$O(n)$。

## 3976 - Maximum Subarray Sum After Multiplier

**题意**

题目链接：[Maximum Subarray Sum After Multiplier](https://leetcode.com/problems/maximum-subarray-sum-after-multiplier/description/)

给定整数数组 `nums` 和正整数 `k`。必须选择一个非空连续区间，并且恰好执行以下一种操作：

1. 将区间内每个数乘以 `k`；
2. 将区间内每个数除以 `k`。

除法规定：正数向下取整，负数向上取整，也就是 C++ 整数除法的向零截断。

操作完成后，再选择一个非空子数组，最大化该子数组的元素和。执行操作的区间和最终求和的子数组可以不同。

- `1 <= nums.length <= 10^5`
- `-10^5 <= nums[i] <= 10^5`
- `1 <= k <= 10^5`

**解题思路**

设操作区间为 `O`，最终求和的子数组为 `A`。根据两个区间是否相交，分为两种情况。

### 1. 操作区间与答案子数组相交

如果 `O` 与 `A` 相交，那么 `O` 在 `A` 外面的部分不会影响 `A` 的和。因此可以把操作区间缩短为 `O ∩ A`，仍然得到一个非空连续区间。

所以相交情况下，可以认为操作区间完全位于答案子数组内部。

固定一种变换函数 `g`：

- 乘法：`g(x) = x * k`；
- 除法：`g(x) = x / k`，向零取整。

从左到右扫描数组，维护三个状态：

- `d0`：答案子数组以当前位置结尾，操作还没有开始；
- `d1`：答案子数组以当前位置结尾，当前位置处于操作区间内部；
- `d2`：答案子数组以当前位置结尾，操作区间已经结束。

状态只能按照：

```text
操作前 -> 操作中 -> 操作后
```

变化。

设当前元素为 `x`，变换后的值为 `y = g(x)`，则：

$$
nd_0=\max(x,d_0+x)
$$

$$
nd_1=\max(y,d_0+y,d_1+y)
$$

$$
nd_2=\max(d_1+x,d_2+x)
$$

因为必须恰好执行一次操作，`d0` 不能作为最终答案，最终答案只能来自 `d1` 或 `d2`。

### 2. 操作区间与答案子数组不相交

如果两个区间不相交，操作不会影响答案子数组。因此答案是原数组中的某个子数组和。

但操作区间必须非空，所以答案子数组不能覆盖整个数组，必须是一个真子数组。任意真子数组至少不包含数组首元素或尾元素，因此最大真子数组和为：

$$
\max(\operatorname{Kadane}(0,n-2),\operatorname{Kadane}(1,n-1))
$$

当 `n = 1` 时，不存在两个不相交的非空区间，不需要计算这一部分。

**代码**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    using LL = long long;
    static constexpr LL INF = (1LL << 62);

    LL solveIntersect(const vector<int>& nums, int k, bool divide) {
        LL d0 = -INF;
        LL d1 = -INF;
        LL d2 = -INF;
        LL ans = -INF;

        for (int x : nums) {
            LL y = divide ? 1LL * x / k : 1LL * x * k;

            LL nd0 = max(1LL * x, d0 + x);
            LL nd1 = max({y, d0 + y, d1 + y});
            LL nd2 = max(d1 + x, d2 + x);

            d0 = nd0;
            d1 = nd1;
            d2 = nd2;

            ans = max({ans, d1, d2});
        }

        return ans;
    }

    LL kadane(const vector<int>& nums, int left, int right) {
        LL cur = nums[left];
        LL ans = nums[left];

        for (int i = left + 1; i <= right; i++) {
            cur = max(1LL * nums[i], cur + nums[i]);
            ans = max(ans, cur);
        }

        return ans;
    }

public:
    long long maxSubarraySum(vector<int>& nums, int k) {
        int n = nums.size();

        LL ans = max(
            solveIntersect(nums, k, false),
            solveIntersect(nums, k, true)
        );

        if (n >= 2) {
            ans = max({
                ans,
                kadane(nums, 0, n - 2),
                kadane(nums, 1, n - 1)
            });
        }

        return ans;
    }
};
```

**正确性证明**

若操作区间与答案子数组相交，把操作区间缩短为它们的交集不会改变答案子数组中的任何元素，因此相交情况一定可以由三状态 DP 表示。

三状态 DP 中，`d0 -> d1 -> d2` 恰好表示操作区间尚未开始、正在进行、已经结束。每个状态都枚举了重新开始答案子数组、开始操作、继续操作、结束操作和继续答案子数组等转移，因此完整覆盖所有相交方案。

若两个区间不相交，操作不改变答案子数组。由于操作区间必须非空，答案子数组必须是真子数组，使用去掉首元素或去掉尾元素后的两次 Kadane 即可覆盖全部真子数组。

乘法和除法分别计算后取最大值，因而算法返回所有合法方案中的最大结果。

**复杂度分析**

两种操作各扫描一次数组，两个真子数组的 Kadane 也各扫描一次。

时间复杂度：$O(n)$。

空间复杂度：$O(1)$。

## 3977 - Minimum Time to Reach Target With Limited Power

**题意**

题目链接：[Minimum Time to Reach Target With Limited Power](https://leetcode.com/problems/minimum-time-to-reach-target-with-limited-power/description/)

给定一个有向带权图。每条边 `[u,v,t]` 表示从 `u` 到 `v` 需要 `t` 秒。

信号从 `source` 出发，初始拥有 `power` 点电量。每次从节点 `u` 通过任意一条出边时，都需要消耗 `cost[u]` 点电量；到达节点时不消耗电量。只有剩余电量不少于 `cost[u]` 时，才能离开 `u`。

返回：

1. 到达 `target` 的最短时间；
2. 在所有最短时间路径中，最大的剩余电量。

如果无法到达，返回 `[-1,-1]`。

- `1 <= n <= 1000`
- `0 <= edges.length <= 1000`
- `1 <= power <= 1000`
- `1 <= cost[i] <= 2000`
- `1 <= t_i <= 10^9`

**解题思路**

### 1. 状态设计

不能只记录到达某个节点的最短时间，因为时间更短的路径可能消耗了更多电量，无法继续前进；时间稍长但剩余电量更多的路径可能最终更优。

定义：

$$
dis[c][u]
$$

表示从 `source` 出发，恰好消耗 `c` 点电量到达节点 `u` 的最短时间。

初始状态为：

$$
dis[0][source]=0
$$

若当前状态为 `(c,u)`，沿有向边 `u -> v` 前进，则：

$$
nc=c+cost[u]
$$

当 `nc <= power` 时，进行转移：

$$
dis[nc][v]=\min(dis[nc][v],dis[c][u]+t)
$$

注意消耗的是出发节点 `u` 的 `cost[u]`。

### 2. 为什么可以按电量做动态规划

由于：

$$
cost[u]\ge1
$$

每次转移都会满足：

$$
nc=c+cost[u]>c
$$

也就是说，扩展状态图中的边永远从较小的已用电量指向较大的已用电量，不可能回到之前的电量层。因此状态图是 DAG，按照 `c = 0,1,...,power` 的顺序处理即可，不需要 Dijkstra。

### 3. 选择最终状态

枚举所有 `dis[c][target]`，先选择时间最小的状态。

剩余电量为：

$$
power-c
$$

在时间相同时，剩余电量越多等价于已消耗电量 `c` 越小。因此用 `(时间最小，已用电量最小)` 作为比较顺序即可。

**代码**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    using LL = long long;
    static constexpr LL INF = (1LL << 62);

public:
    vector<long long> minTimeMaxPower(
        int n,
        vector<vector<int>>& edges,
        int power,
        vector<int>& cost,
        int source,
        int target
    ) {
        vector<vector<pair<int, int>>> graph(n);

        for (const auto& edge : edges) {
            graph[edge[0]].push_back({edge[1], edge[2]});
        }

        vector<vector<LL>> dis(
            power + 1,
            vector<LL>(n, INF)
        );

        dis[0][source] = 0;

        for (int used = 0; used <= power; used++) {
            for (int u = 0; u < n; u++) {
                if (dis[used][u] == INF) {
                    continue;
                }

                int nextUsed = used + cost[u];
                if (nextUsed > power) {
                    continue;
                }

                for (auto [v, time] : graph[u]) {
                    dis[nextUsed][v] = min(
                        dis[nextUsed][v],
                        dis[used][u] + time
                    );
                }
            }
        }

        LL bestTime = INF;
        int bestUsed = -1;

        for (int used = 0; used <= power; used++) {
            if (dis[used][target] < bestTime) {
                bestTime = dis[used][target];
                bestUsed = used;
            } else if (dis[used][target] == bestTime &&
                       used < bestUsed) {
                bestUsed = used;
            }
        }

        if (bestTime == INF) {
            return {-1, -1};
        }

        return {bestTime, 1LL * power - bestUsed};
    }
};
```

**正确性证明**

初始状态 `dis[0][source] = 0` 表示不经过任何边到达起点。

若一条路径的最后一条边是 `u -> v`，且经过这条边后使用了 `nc` 点电量，那么经过这条边前使用了：

$$
c=nc-cost[u]
$$

算法会从状态 `(c,u)` 转移到 `(nc,v)`，所以所有合法路径都能被枚举。

因为每次转移都会增加至少一个单位的电量，状态边严格从较小电量层指向较大电量层。按照已使用电量从小到大处理，就是状态图的拓扑序；每个状态的所有前驱都会在它之前被处理，因此 `dis[c][u]` 始终记录该状态的最短时间。

所有到达 `target` 的合法路径都对应某个状态 `(c,target)`。算法先取最小时间；在时间相同时取最小的 `c`，也就是最大的剩余电量。因此最终结果符合题目要求。

**复杂度分析**

设节点数为 `n`，边数为 `m`，初始电量为 `P`。

状态数量为 $O(nP)$，每个电量层扫描一次节点和出边。

时间复杂度：$O(P(n+m))$。

空间复杂度：$O(nP+m)$。

## 知识点总结

本场比赛的四道题分别对应以下模型：

1. **重排不等式贪心**：将选择和处理顺序转化为元素与系数的最优匹配；
2. **区间合并与差集**：先合并离散整数区间，再删除免费区间；
3. **状态机动态规划**：用“操作前、操作中、操作后”描述一次连续区间操作；
4. **资源限制最短路**：把已消耗资源加入状态，并利用资源严格增加得到 DAG 动态规划。
