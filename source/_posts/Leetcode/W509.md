## 3982 - Sum of Integers with Maximum Digit Range

**题意**

题目链接：[Sum of Integers with Maximum Digit Range](https://leetcode.com/problems/sum-of-integers-with-maximum-digit-range/description/)

整数的数字范围定义为其十进制表示中最大数字与最小数字的差。给定整数数组 `nums`，返回数字范围等于数组内最大数字范围的所有元素之和。

- $1\le |nums|\le 100$
- $10\le nums_i\le 10^5$

**解题思路**

遍历每个数的十进制数位，求出最大数字与最小数字，从而得到其数字范围。

扫描数组时维护：

- `best`：当前最大的数字范围；
- `ans`：数字范围等于 `best` 的元素和。

若当前范围更大，之前的元素都不再满足条件，直接令 `ans = x`；若范围相等，则将 `x` 累加到答案中。

**代码**

```cpp
class Solution {
    int digitRange(int x) {
        int mx = 0;
        int mn = 9;

        while (x > 0) {
            int d = x % 10;
            mx = max(mx, d);
            mn = min(mn, d);
            x /= 10;
        }

        return mx - mn;
    }

public:
    int maxDigitRange(vector<int>& nums) {
        int best = -1;
        int ans = 0;

        for (int x : nums) {
            int cur = digitRange(x);

            if (cur > best) {
                best = cur;
                ans = x;
            } else if (cur == best) {
                ans += x;
            }
        }

        return ans;
    }
};
```

**复杂度分析**

设每个整数最多有 $D$ 位。

时间复杂度：$O(|nums|\cdot D)$。本题中 $D\le 6$，可视为 $O(|nums|)$。

空间复杂度：$O(1)$。

**变形**

如果需要统计数字范围达到最小值的元素个数或元素和，只需把维护的最优值方向改为最小值，并在更优值出现时重置相应统计量。

## 3983 - Subsequence After One Replacement

**题意**

题目链接：[Subsequence After One Replacement](https://leetcode.com/problems/subsequence-after-one-replacement/description/)

给定两个仅含小写字母的字符串 `s`、`t`。可以至多选择 `s` 中一个位置并替换为任意小写字母，判断操作后 `s` 是否能成为 `t` 的子序列。

- $1\le |s|,|t|\le 10^5$

**解题思路**

从左到右扫描 `t`，维护两个最长前缀匹配长度：

- $d_0$：未使用替换时，已经匹配的 `s` 前缀长度；
- $d_1$：至多使用一次替换时，已经匹配的 `s` 前缀长度。

设当前扫描到 `t` 中字符 $c$。跳过 $c$ 时状态不变；如果 $c$ 等于对应的下一个 `s` 字符，则可正常匹配并将状态加一。

此外，若 $d_0<|s|$，可以将 `s[d0]` 替换为 $c$，从 $d_0$ 转移到 $d_1=d_0+1$。同一个 $c$ 不能同时匹配多个位置，因此每轮先保存旧状态，再计算新状态。

两个状态分别保存各自条件下的最长可匹配前缀。所有转移都只会把一个 `t` 字符用于至多一个 `s` 位置，且完整覆盖了跳过、正常匹配与使用替换三种选择，因此最后 $d_1=|s|$ 当且仅当存在合法方案。

**代码**

```cpp
class Solution {
public:
    bool canMakeSubsequence(string s, string t) {
        int n = s.size();

        if (n > static_cast<int>(t.size())) {
            return false;
        }

        int d0 = 0;
        int d1 = 0;

        for (char c : t) {
            int n0 = d0;
            int n1 = d1;

            if (d0 < n && s[d0] == c) {
                n0 = d0 + 1;
            }

            if (d1 < n && s[d1] == c) {
                n1 = max(n1, d1 + 1);
            }

            if (d0 < n) {
                n1 = max(n1, d0 + 1);
            }

            d0 = n0;
            d1 = n1;
        }

        return d1 == n;
    }
};
```

**复杂度分析**

时间复杂度：$O(|t|)$。

空间复杂度：$O(1)$。

**变形**

如果允许至多 $k$ 次替换，可以维护 $dp_j$：使用至多 $j$ 次替换时可匹配的最长前缀。每个 `t` 字符倒序更新 $j$，总时间复杂度为 $O(k|t|)$。

## 3984 - Divisible Game

**题意**

题目链接：[Divisible Game](https://leetcode.com/problems/divisible-game/description/)

给定正整数数组 `nums`。Alice 选择整数 $k>1$ 和一个非空子数组 $[l,r]$：能被 $k$ 整除的元素计入 Alice 分数，不能整除的元素计入 Bob 分数。目标是最大化 Alice 分数减 Bob 分数；若有多个 $k$ 达到最大值，选择其中最小的 $k$。返回最大分差与所选 $k$ 的乘积，对 $10^9+7$ 取模。

- $1\le |nums|\le 1000$
- $1\le nums_i\le 10^6$

**解题思路**

固定 $k$ 后，将每个元素改写为：

$$
b_i=
\begin{cases}
nums_i, & k\mid nums_i,\\
-nums_i, & k\nmid nums_i.
\end{cases}
$$

所求分差就是数组 $b$ 的最大非空子数组和。

若数组中存在大于 $1$ 的元素，选择该元素自身作为 $k$ 并只选该位置，可以取得正分差。因此，不能整除任何元素的 $k$ 不可能最优；只需要枚举数组元素所有大于 $1$ 的约数。若所有元素均为 $1$，任意 $k$ 的最优分差均为 $-1$，按题意选择最小的 $k=2$。

对每个候选约数 $k$，记录所有可整除位置：

$$
p_1<p_2<\cdots<p_m
$$

最优子数组的两端一定可以取为这些位置。若端点不能被 $k$ 整除，它的贡献为负数，删除该端点会使分差更大。

设相邻可整除位置为 $a,b$，两者之间所有元素均贡献负数。使用前缀和求出中间元素和 `gap` 后，令 `cur` 表示以当前位置结尾的最优分差：

$$
cur=\max(nums_b,\ cur-gap+nums_b)
$$

这就是仅在正贡献位置上运行的 Kadane 算法。枚举所有 $k$ 后，按分差优先、$k$ 次之的顺序更新答案。

**代码**

```cpp
class Solution {
public:
    int divisibleGame(vector<int>& nums) {
        const long long MOD = 1000000007LL;
        int n = nums.size();
        int mx = *max_element(nums.begin(), nums.end());

        vector<vector<int>> pos(mx + 1);
        vector<int> candidates;

        for (int i = 0; i < n; i++) {
            int x = nums[i];

            for (int d = 1; 1LL * d * d <= x; d++) {
                if (x % d != 0) {
                    continue;
                }

                int q = x / d;

                if (d > 1) {
                    if (pos[d].empty()) {
                        candidates.push_back(d);
                    }
                    pos[d].push_back(i);
                }

                if (q > 1 && q != d) {
                    if (pos[q].empty()) {
                        candidates.push_back(q);
                    }
                    pos[q].push_back(i);
                }
            }
        }

        if (candidates.empty()) {
            return static_cast<int>(MOD - 2);
        }

        vector<long long> pre(n + 1);
        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i];
        }

        long long best = LLONG_MIN;
        int bestK = INT_MAX;

        for (int k : candidates) {
            const vector<int>& p = pos[k];
            long long cur = nums[p[0]];
            long long value = cur;

            for (int i = 1; i < static_cast<int>(p.size()); i++) {
                int a = p[i - 1];
                int b = p[i];
                long long gap = pre[b] - pre[a + 1];

                cur = max<long long>(nums[b], cur - gap + nums[b]);
                value = max(value, cur);
            }

            if (value > best || (value == best && k < bestK)) {
                best = value;
                bestK = k;
            }
        }

        long long ans = (best % MOD) * bestK % MOD;
        return static_cast<int>((ans + MOD) % MOD);
    }
};
```

**复杂度分析**

设 $A=\max(nums_i)$，$\tau(x)$ 为 $x$ 的大于 $1$ 的约数数量，并定义：

$$
D=\sum_i\tau(nums_i)
$$

枚举约数需要 $O(n\sqrt A)$。第二阶段中，每个“元素可被其约数整除”的关系只会出现在一个位置表中并被处理一次，因此所有稀疏 Kadane 转移的总量为 $O(D)$。

时间复杂度：$O(n\sqrt A+D)$，也可简化为 $O(n\sqrt A)$。

空间复杂度：$O(A+D)$。

**变形**

若 $k$ 的候选范围很小，可以直接为每个 $k$ 构造贡献数组并运行普通 Kadane。若评分规则改为可整除与不可整除对应任意权值，仍可用相同的候选约数与最大子数组和框架处理。

## 3985 - Palindromic Subarray Sum

**题意**

题目链接：[Palindromic Subarray Sum](https://leetcode.com/problems/palindromic-subarray-sum/description/)

给定正整数数组 `nums`，求所有回文子数组中元素和的最大值。

- $1\le |nums|\le 10^5$
- $1\le nums_i\le 10^9$

**解题思路**

回文子数组分为奇数长度与偶数长度两类。由于所有元素均为正数，固定一个中心时，较长回文由较短回文向两侧扩展得到，每次扩展增加两个正数，元素和严格变大。因此，每个中心只需要考察最长回文子数组。

Manacher 算法只依赖相等判断，也可以直接用于整数数组。定义：

- $d1_i$：以 $i$ 为中心的最长奇回文半径，对应区间 $[i-d1_i+1,i+d1_i-1]$；
- $d2_i$：中心位于 $i-1,i$ 之间的最长偶回文半径，对应区间 $[i-d2_i,i+d2_i-1]$。

Manacher 在维护当前最右回文区间的同时，利用对称中心给新位置一个初始半径，再继续向两侧扩展，因此两类半径都能在线性时间求出。

最后预处理前缀和 $pre_i=\sum_{j=0}^{i-1}nums_j$。每个最长回文区间 $[l,r]$ 的元素和为 $pre_{r+1}-pre_l$，枚举所有中心取最大值即可。

**代码**

```cpp
class Solution {
public:
    long long getSum(vector<int>& nums) {
        int n = nums.size();
        vector<int> d1(n);

        for (int i = 0, l = 0, r = -1; i < n; i++) {
            int k = i > r ? 1 : min(d1[l + r - i], r - i + 1);

            while (i - k >= 0 && i + k < n &&
                   nums[i - k] == nums[i + k]) {
                k++;
            }

            d1[i] = k;

            if (i + k - 1 > r) {
                l = i - k + 1;
                r = i + k - 1;
            }
        }

        vector<int> d2(n);

        for (int i = 0, l = 0, r = -1; i < n; i++) {
            int k = i > r ? 0 : min(d2[l + r - i + 1], r - i + 1);

            while (i - k - 1 >= 0 && i + k < n &&
                   nums[i - k - 1] == nums[i + k]) {
                k++;
            }

            d2[i] = k;

            if (i + k - 1 > r) {
                l = i - k;
                r = i + k - 1;
            }
        }

        vector<long long> pre(n + 1);
        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i];
        }

        long long ans = 0;

        for (int i = 0; i < n; i++) {
            int l = i - d1[i] + 1;
            int r = i + d1[i] - 1;
            ans = max(ans, pre[r + 1] - pre[l]);
        }

        for (int i = 0; i < n; i++) {
            if (d2[i] == 0) {
                continue;
            }

            int l = i - d2[i];
            int r = i + d2[i] - 1;
            ans = max(ans, pre[r + 1] - pre[l]);
        }

        return ans;
    }
};
```

**复杂度分析**

Manacher、前缀和以及中心枚举均为线性处理。

时间复杂度：$O(n)$。

空间复杂度：$O(n)$。

**变形**

如果数组允许负数，同一中心的最长回文未必具有最大元素和，需要比较该中心所有回文半径对应的区间和。若只需判断区间是否回文，也可以使用双哈希配合二分半径，时间复杂度为 $O(n\log n)$。
