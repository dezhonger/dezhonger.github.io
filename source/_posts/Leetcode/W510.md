## 3986 - Number of Elapsed Seconds Between Two Times

**题意**

题目链接：[Number of Elapsed Seconds Between Two Times](https://leetcode.com/problems/number-of-elapsed-seconds-between-two-times/description/)

给定两个格式固定为 `HH:MM:SS` 的当天时间 `startTime` 和 `endTime`，且保证结束时间不早于开始时间。求两者之间经过的秒数。

- `startTime.length == endTime.length == 8`；
- `00 <= HH <= 23`，`00 <= MM, SS <= 59`；
- 不会跨天。

**解题思路**

将一个时间统一换算为从 `00:00:00` 开始经过的秒数：

$$
f(\text{HH:MM:SS})=HH\times3600+MM\times60+SS
$$

答案为 `f(endTime) - f(startTime)`。

字符串格式固定，直接按下标读取两位数字即可：小时位于 `[0, 1]`，分钟位于 `[3, 4]`，秒位于 `[6, 7]`。

**代码**

```cpp
class Solution {
    int toSeconds(const string& s) {
        int h = (s[0] - '0') * 10 + (s[1] - '0');
        int m = (s[3] - '0') * 10 + (s[4] - '0');
        int sec = (s[6] - '0') * 10 + (s[7] - '0');
        return h * 3600 + m * 60 + sec;
    }

public:
    int secondsBetweenTimes(string startTime, string endTime) {
        return toSeconds(endTime) - toSeconds(startTime);
    }
};
```

**复杂度分析**

时间复杂度：$O(1)$。

空间复杂度：$O(1)$。

**变形**

若允许跨天且 `endTime` 代表次日时间，只需在结束秒数更小时额外加上一天的秒数 `24 * 60 * 60`。

## 3987 - Minimum Total Cost to Process All Elements

**题意**

题目链接：[Minimum Total Cost to Process All Elements](https://leetcode.com/problems/minimum-total-cost-to-process-all-elements/description/)

初始有 `k` 单位资源，需要依次处理数组 `nums` 中的所有元素；处理 `nums[i]` 要消耗 `nums[i]` 单位资源。资源不足时可以执行补充操作，每次增加固定的 `k` 单位资源。第 `1, 2, \ldots` 次补充的代价分别为 `1, 2, \ldots`，求最小总代价，答案对 $10^9+7$ 取模。

- $1\le |nums|\le 10^5$；
- $1\le nums_i,k\le 10^9$。

**解题思路**

设所有元素之和为：

$$
S=\sum_i nums_i
$$

若总共补充了 $t$ 次，整个过程中可获得的资源总量为 `(t + 1)k`，因此必须有：

$$
(t+1)k\ge S
$$

又由于 `nums[i]` 都是正数，处理前缀所需资源随前缀长度单调增加。只要最终资源总量足够，就总能在某个元素处理前补充到足够的资源；因此最少补充次数只由总和决定：

$$
t=\left\lceil\frac{S}{k}\right\rceil-1=\left\lfloor\frac{S-1}{k}\right\rfloor
$$

第 `i` 次操作的成本为 `i`，总代价为三角数：

$$
1+2+\cdots+t=\frac{t(t+1)}2
$$

`t` 最大可达 $10^{14}$，不能先在整数范围内计算乘积。将一个偶数因子先除以 `2`，再对两个因子分别取模相乘即可。

**代码**

```cpp
class Solution {
public:
    int minimumCost(vector<int>& nums, int k) {
        static constexpr long long MOD = 1000000007LL;

        long long sum = 0;
        for (int x : nums) {
            sum += x;
        }

        long long t = (sum - 1) / k;
        long long a = t;
        long long b = t + 1;

        if (a % 2 == 0) {
            a /= 2;
        } else {
            b /= 2;
        }

        return static_cast<int>((a % MOD) * (b % MOD) % MOD);
    }
};
```

**复杂度分析**

时间复杂度：$O(|nums|)$。

空间复杂度：$O(1)$。

**变形**

若每次补充增加的资源量不再固定，或允许 `nums[i]` 为负数，前缀需求不再只由最终总和决定，需要重新维护每个前缀的最小补充次数。

## 3988 - Create Grid With Exactly K Paths I

**题意**

题目链接：[Create Grid With Exactly K Paths I](https://leetcode.com/problems/create-grid-with-exactly-k-paths-i/description/)

构造一个 `m x n` 的 `.`、`#` 网格，使左上角到右下角、只能向右或向下移动的有效路径数恰好为 `k`。无解时返回空数组。

- $1\le m,n\le10$；
- $1\le k\le4$。

**解题思路**

`k` 的范围很小，可以预先准备若干个小型构造模块（gadget）。无障碍的 `h x w` 网格路径数为：

$$
\binom{h+w-2}{h-1}
$$

因此可直接得到：

| 路径数 | 构造模块 |
| --- | --- |
| 1 | `1 x 1` 全空 |
| 2 | `2 x 2` 全空 |
| 3 | `2 x 3` 或 `3 x 2` 全空 |
| 4 | `2 x 4`、`4 x 2` 全空，或 `3 x 3` 特殊模块 |

当 `k = 4` 且两维都不足 `4` 时，`3 x 3` 模块：

```text
..#
...
#..
```

到右下角恰有 `4` 条路径。

将模块放在左上角后，从其右下角向右延伸到最后一列，再沿最后一列向下延伸到终点。其余格子全部设为 `#`，模块出口之后就只剩唯一通道，故不会改变模块内部的路径数。

**代码**

```cpp
class Solution {
    void fillRectangle(vector<string>& grid, int h, int w) {
        for (int i = 0; i < h; i++) {
            for (int j = 0; j < w; j++) {
                grid[i][j] = '.';
            }
        }
    }

public:
    vector<string> createGrid(int m, int n, int k) {
        vector<string> grid(m, string(n, '#'));
        int h = 1;
        int w = 1;

        if (k == 1) {
            grid[0][0] = '.';
        } else if (k == 2) {
            if (m < 2 || n < 2) {
                return {};
            }
            h = w = 2;
            fillRectangle(grid, h, w);
        } else if (k == 3) {
            if (m >= 2 && n >= 3) {
                h = 2;
                w = 3;
                fillRectangle(grid, h, w);
            } else if (m >= 3 && n >= 2) {
                h = 3;
                w = 2;
                fillRectangle(grid, h, w);
            } else {
                return {};
            }
        } else {
            if (m >= 2 && n >= 4) {
                h = 2;
                w = 4;
                fillRectangle(grid, h, w);
            } else if (m >= 4 && n >= 2) {
                h = 4;
                w = 2;
                fillRectangle(grid, h, w);
            } else if (m >= 3 && n >= 3) {
                h = w = 3;
                grid[0][0] = grid[0][1] = '.';
                grid[1][0] = grid[1][1] = grid[1][2] = '.';
                grid[2][1] = grid[2][2] = '.';
            } else {
                return {};
            }
        }

        for (int j = w - 1; j < n; j++) {
            grid[h - 1][j] = '.';
        }
        for (int i = h - 1; i < m; i++) {
            grid[i][n - 1] = '.';
        }

        return grid;
    }
};
```

**复杂度分析**

时间复杂度：$O(mn)$。

空间复杂度：$O(mn)$，即返回网格本身。

**变形**

若 `k` 的范围更大，不能再枚举固定模块。可以将 `k` 按二进制拆分，并用能够产生对应路径数的模块进行组合。

## 3989 - Maximum Consistent Columns in a Grid

**题意**

题目链接：[Maximum Consistent Columns in a Grid](https://leetcode.com/problems/maximum-consistent-columns-in-a-grid/description/)

可以删除若干列，但至少保留一列且相对顺序不能改变。保留后的相邻两列 `a < b` 必须在每一行都满足：

$$
|grid_{i,b}-grid_{i,a}|\le limit
$$

求最多能保留多少列。

- $1\le m,n\le250$；
- $-10^5\le grid_{i,j}\le10^5$。

**解题思路**

把每列看作一个节点。对于 `i < j`，若所有行都满足：

$$
|grid_{r,j}-grid_{r,i}|\le limit
$$

则可以在列 `i` 后保留列 `j`。由于边永远从小下标指向大下标，得到一张 DAG；题目就是求其中包含节点数最多的路径。

定义 `dp[j]` 为以第 `j` 列结尾时最多能保留的列数。单独保留一列总是合法，因此初始值为 `1`。枚举所有前驱 `i < j`，若两列兼容，则：

$$
dp[j]=\max(dp[j],dp[i]+1)
$$

注意只需要检查保留后相邻的两列；被删除的列不需要满足任何条件。因此这不是所有列两两兼容的最大团问题，而是一个保持下标顺序的最长子序列问题。

**代码**

```cpp
class Solution {
public:
    int maxConsistentColumns(vector<vector<int>>& grid, int limit) {
        int m = grid.size();
        int n = grid[0].size();
        vector<int> dp(n, 1);
        int ans = 1;

        for (int j = 0; j < n; j++) {
            for (int i = 0; i < j; i++) {
                bool compatible = true;

                for (int r = 0; r < m; r++) {
                    if (abs(grid[r][j] - grid[r][i]) > limit) {
                        compatible = false;
                        break;
                    }
                }

                if (compatible) {
                    dp[j] = max(dp[j], dp[i] + 1);
                }
            }
            ans = max(ans, dp[j]);
        }

        return ans;
    }
};
```

**复杂度分析**

共有 $O(n^2)$ 对有序列，判断一对列是否兼容需要检查 $m$ 行。

时间复杂度：$O(mn^2)$，最大约为 $1.56\times10^7$ 次比较。

空间复杂度：$O(n)$。

**变形**

若行数很小而列数很大，可将每列视为一个低维点。转移即为在历史点中查询位于以当前点为中心、边长 `2 * limit` 的高维盒子内的最大 `dp`，可进一步考虑范围树或 KD-Tree；本题维度最高为 `250`，直接枚举前驱更稳妥。
