## 3994 - Even Number of Knight Moves

**题意**

题目链接：[Even Number of Knight Moves](https://leetcode.com/problems/even-number-of-knight-moves/description/)

给定国际象棋 `8 x 8` 棋盘上的两个位置 `start`、`target`。判断马是否能从 `start` 经过偶数步到达 `target`。

- `start.length == target.length == 2`；
- 坐标均在 `[0, 7]` 内。

**解题思路**

按照坐标和的奇偶性给棋盘二染色。马的一步移动坐标增量为 $(\pm1,\pm2)$ 或 $(\pm2,\pm1)$，横纵坐标和的变化一定是奇数，因此每走一步都会切换颜色。

```text
偶数步：起点和终点颜色相同
奇数步：起点和终点颜色不同
```

标准 `8 x 8` 棋盘的马移动图连通，所以同色这一必要条件也是充分条件。直接比较两个坐标和的奇偶性即可。

**代码**

```cpp
class Solution {
public:
    bool canReach(vector<int>& start, vector<int>& target) {
        return ((start[0] + start[1]) & 1) ==
               ((target[0] + target[1]) & 1);
    }
};
```

**复杂度分析**

时间复杂度：$O(1)$。

空间复杂度：$O(1)$。

**变形**

对于任意连通二分图，两个节点之间是否存在偶数长度路径，也可以通过判断二分图染色是否相同解决。若图不连通，还需要额外确认两个节点位于同一连通块。

## 3995 - Transform Binary String Using Subsequence Sort

**题意**

题目链接：[Transform Binary String Using Subsequence Sort](https://leetcode.com/problems/transform-binary-string-using-subsequence-sort/description/)

给定二进制串 `s` 和若干包含 `0`、`1`、`?` 的等长查询串。一次操作可以选择 `s` 的任意子序列并升序排序。对每个查询串，判断能否替换其中所有 `?`，使其可以从 `s` 经过若干次操作得到。

- $1\le |s|\le2000$；
- $1\le |strs|\le2000$；
- 每个查询串长度均为 $|s|$。

**解题思路**

对二进制串排序子序列，本质上只会将 `0` 向左、`1` 向右移动。特别地，可以选择一对位置为 `10` 的子序列，把它排序为 `01`。因此，对没有 `?` 的目标串 `t`，可达的充要条件为：

1. `s`、`t` 的 `1` 数量相同；
2. 对每个前缀，`t` 中的 `1` 数量不超过 `s` 中的 `1` 数量。

第一个条件来自字符数量不变。第二个条件来自 `1` 只能向右移动。反过来，若两个条件成立，则第 `k` 个 `1` 在 `t` 中的位置不会早于它在 `s` 中的位置；从右向左反复执行 `10 -> 01`，即可将每个 `1` 移到目标位置。

现在考虑一个查询串 `t`。设：

- `tot`：`s` 中 `1` 的总数；
- `one`：`t` 中固定的 `1` 数；
- `qs`：`t` 中 `?` 的总数；
- `need = tot - one`：必须填成 `1` 的 `?` 数量。

若 `need` 不在 `[0, qs]` 内，显然无解。为让每个前缀中的 `1` 尽可能少，所有需要填为 `1` 的 `?` 都应尽量放在右侧。

扫描一个前缀时，记前缀内固定 `1` 数为 `fixedOne`、前缀 `?` 数为 `prefixQuestion`。后缀剩余 `?` 数为：

$$
suffixQuestion=qs-prefixQuestion
$$

后缀容纳不下的 `1` 必须出现在当前前缀，所以该前缀中最少的 `1` 数为：

$$
fixedOne+\max(0,need-suffixQuestion)
$$

将其与 `s` 的对应前缀 `1` 数比较即可。

**代码**

```cpp
class Solution {
public:
    vector<bool> transformStr(string s, vector<string>& strs) {
        int n = s.size();
        vector<int> prefixOnes(n + 1);

        for (int i = 0; i < n; i++) {
            prefixOnes[i + 1] = prefixOnes[i] + (s[i] == '1');
        }

        int totalOnes = prefixOnes[n];
        vector<bool> ans;
        ans.reserve(strs.size());

        for (const string& t : strs) {
            int one = 0;
            int question = 0;

            for (char c : t) {
                one += (c == '1');
                question += (c == '?');
            }

            int need = totalOnes - one;
            if (need < 0 || need > question) {
                ans.push_back(false);
                continue;
            }

            int fixedOne = 0;
            int prefixQuestion = 0;
            bool ok = true;

            for (int i = 0; i < n; i++) {
                fixedOne += (t[i] == '1');
                prefixQuestion += (t[i] == '?');

                int suffixQuestion = question - prefixQuestion;
                int minimumOnes = fixedOne + max(0, need - suffixQuestion);

                if (minimumOnes > prefixOnes[i + 1]) {
                    ok = false;
                    break;
                }
            }

            ans.push_back(ok);
        }

        return ans;
    }
};
```

**复杂度分析**

设 $n=|s|$、$q=|strs|$。预处理时间为 $O(n)$；每个查询扫描两遍。

时间复杂度：$O(n+qn)$。

空间复杂度：$O(n)$，不计返回数组。

**变形**

这类问题的核心是前缀上界。若需要在若干个可选位置放置固定数量的 `1`，且目标是让每个前缀的 `1` 尽量少，应优先将 `1` 放到最右侧可选位置。

## 3996 - Minimum Number of Groups After String Transformation

**题意**

题目链接：[Minimum Number of Groups After String Transformation](https://leetcode.com/problems/minimum-number-of-groups-after-string-transformation/description/)

给定字符串数组 `words`。对任意字符串，将偶数下标字符组成的子序列 `E` 和奇数下标字符组成的子序列 `O` 分别循环右移任意次数，再交错放回原下标奇偶性。若一个字符串能通过一次该操作得到另一个字符串，则二者等价。将所有字符串划分为满足组内两两等价的最少组数。

- $1\le |words|\le10^5$；
- 所有字符串总长度不超过 $5\times10^5$。

**解题思路**

一次变换中，偶数下标字符只会在偶数下标间循环移动，奇数下标字符同理。因此两个字符串等价，当且仅当：

```text
它们的偶数下标子序列互为循环移位，且奇数下标子序列也互为循环移位。
```

循环移位类可以用字典序最小循环表示作为唯一规范表示。这里使用经典的 **Booth 算法** 在线性时间求最小表示。

对于每个单词：

1. 拆出偶数子序列 `even`、奇数子序列 `odd`；
2. 分别计算 `booth(even)`、`booth(odd)`；
3. 以 `booth(even) + '#' + booth(odd)` 作为签名，插入哈希集合。

`#` 不属于小写字母，可以安全作为分隔符。不同签名对应不同等价类，哈希集合大小即为最少分组数。

**代码**

```cpp
class Solution {
    // Booth 算法：返回字典序最小循环表示。
    string booth(const string& s) {
        int n = s.size();
        if (n == 0) {
            return "";
        }

        string doubled = s + s;
        int i = 0;
        int j = 1;

        while (i < n && j < n) {
            int k = 0;

            while (k < n && doubled[i + k] == doubled[j + k]) {
                k++;
            }

            if (k == n) {
                break;
            }

            if (doubled[i + k] > doubled[j + k]) {
                i += k + 1;
                if (i == j) {
                    i++;
                }
            } else {
                j += k + 1;
                if (i == j) {
                    j++;
                }
            }
        }

        return doubled.substr(min(i, j), n);
    }

public:
    int minimumGroups(vector<string>& words) {
        unordered_set<string> signatures;
        signatures.reserve(words.size() * 2);

        for (const string& word : words) {
            string even;
            string odd;
            even.reserve((word.size() + 1) / 2);
            odd.reserve(word.size() / 2);

            for (int i = 0; i < static_cast<int>(word.size()); i++) {
                if (i % 2 == 0) {
                    even += word[i];
                } else {
                    odd += word[i];
                }
            }

            string signature = booth(even) + "#" + booth(odd);
            signatures.insert(move(signature));
        }

        return signatures.size();
    }
};
```

**正确性说明**

偶数、奇数下标子序列可以独立循环移动，故二者的循环移位类完全刻画了字符串等价关系。Booth 算法对同一循环移位类总会返回同一个字典序最小代表元，因而两个字符串签名相同当且仅当它们等价。等价关系的每个等价类恰好对应一个可合并的组，所以不同签名数量就是最少组数。

**复杂度分析**

设所有字符串总长度为 $L$。拆分、两次 Booth、签名构造与哈希的总处理长度均为线性。

时间复杂度：$O(L)$，平均意义下包含哈希插入。

空间复杂度：$O(L)$，用于保存不同签名及单个字符串的临时数据。

**变形**

最小循环表示还可通过 Duval 算法在线性时间求出；若题目本身需要后缀数组或哈希，亦可在 `s + s` 上比较不同循环起点。单独处理该问题时，Booth 算法的语义最直接。
