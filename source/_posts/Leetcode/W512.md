## 4000 - Largest Integer With Given Digit Sum

**题意**

题目链接：[Largest Integer With Given Digit Sum](https://leetcode.com/problems/largest-integer-with-given-digit-sum/description/)

给定非负整数 `n` 和 `s`，求数字和恰好为 `s`、位数不超过 `n` 的最大非负整数；不存在时返回 `-1`。

- $1\le n\le5$；
- $0\le s\le100$。

**解题思路**

每一位最大为 `9`，所以 `n` 位数能够容纳的最大数字和为 $9n$。若 $s>9n$，答案不存在。

否则从最高位向最低位构造答案。为了让整数尽可能大，应将剩余数字和尽量放在当前高位：

$$
d=\min(9,s)
$$

放入当前位后令 $s\leftarrow s-d$，继续处理下一位。最终答案一定具有如下形式：

```text
999...9x000...0
```

其中 `x` 可能不存在，也可能是 `1` 到 `8`。当原始 `s = 0` 时，循环会自然得到 `0`，不需要单独处理。

**代码**

```cpp
class Solution {
public:
    int largestInteger(int n, int s) {
        if (s > 9 * n) {
            return -1;
        }

        int ans = 0;

        for (int i = 0; i < n; i++) {
            int digit = min(9, s);
            ans = ans * 10 + digit;
            s -= digit;
        }

        return ans;
    }
};
```

**正确性说明**

假设某个更高位仍能增加 `1`，却把这 `1` 的数字和放在了更低位。将它从低位移动到高位不会改变数字和，但会让整数增加 $10^i-10^j>0$，其中 $i>j$。因此最优答案必须优先填满高位，算法逐位取 `min(9, s)` 得到的就是最大整数。

**复杂度分析**

时间复杂度：$O(n)$。

空间复杂度：$O(1)$。

**变形**

如果要求答案恰好有 `n` 位，那么除了 $s\le9n$，还需要 $s\ge1$；构造方法不变，因为贪心会自动保证最高位非零。若允许返回字符串，同样的写法可以处理远大于机器整数范围的 `n`。

## 4001 - Aggregate Two Time Series

**题意**

题目链接：[Aggregate Two Time Series](https://leetcode.com/problems/aggregate-two-time-series/description/)

给定两个按照时间戳严格递增的时间序列 `series1` 和 `series2`，每个元素为 `[timestamp, value]`。

对于某个序列中不存在的时间戳 `t`，使用该序列里第一个时间戳不小于 `t` 的元素值；若不存在，则使用 `0`。对两个序列所有出现过的时间戳，求对应值之和并按时间戳递增返回。

- 两个序列的长度均在 $[1,10^5]$ 内；
- 时间戳和值均在 $[1,10^9]$ 内。

**解题思路**

缺失值取的是第一个 `timestamp >= t` 的值，相当于 `lower_bound`，而不是常见的“使用之前最近值”。

分别用指针 `i`、`j` 指向两个序列中尚未处理的第一个元素。下一次需要输出的时间戳一定是：

$$
t=\min(series1[i][0],series2[j][0])
$$

若某个指针尚未到达末尾，它当前指向的元素恰好就是该序列中第一个时间戳不小于 `t` 的元素。因此当前和值可以直接由两个指针所指的值相加得到；指针已到末尾时，对应值为 `0`。

输出后，将时间戳等于 `t` 的指针向后移动。两个时间戳可能相同，所以这里必须使用两个独立的 `if`。

**代码**

```cpp
class Solution {
public:
    vector<vector<int>> aggregateTimeSeries(
        vector<vector<int>>& series1,
        vector<vector<int>>& series2
    ) {
        int n = series1.size();
        int m = series2.size();
        int i = 0;
        int j = 0;

        vector<vector<int>> ans;
        ans.reserve(n + m);

        while (i < n || j < m) {
            int timestamp;

            if (i == n) {
                timestamp = series2[j][0];
            } else if (j == m) {
                timestamp = series1[i][0];
            } else {
                timestamp = min(series1[i][0], series2[j][0]);
            }

            int value1 = (i < n ? series1[i][1] : 0);
            int value2 = (j < m ? series2[j][1] : 0);
            ans.push_back({timestamp, value1 + value2});

            if (i < n && series1[i][0] == timestamp) {
                i++;
            }
            if (j < m && series2[j][0] == timestamp) {
                j++;
            }
        }

        return ans;
    }
};
```

**正确性说明**

在每轮开始时，`i`、`j` 分别指向各自序列中第一个尚未经过的时间戳。当前合并时间戳 `t` 是两者中的较小值，因此两个指针所指元素分别是各自序列中第一个时间戳不小于 `t` 的元素；不存在时指针已经到达末尾。算法由此计算出 `t` 的正确和值，并只跳过时间戳恰好为 `t` 的元素，循环不变式继续成立。所有时间戳最终恰好输出一次。

**复杂度分析**

设两个序列长度分别为 $n$、$m$。每个指针只会单调向后移动。

时间复杂度：$O(n+m)$。

空间复杂度：$O(1)$，不计返回数组。

**变形**

如果缺失值改为使用之前最近的时间戳，就需要维护每个序列最后一个已经经过的值；此时语义相当于 `upper_bound(t) - 1`。如果序列数量从两个扩展到 `k` 个，可以用最小堆归并全部时间戳，并维护每个序列当前的候选值。

## 4002 - Count Valid Sequences

**题意**

题目链接：[Count Valid Sequences](https://leetcode.com/problems/count-valid-sequences/description/)

给定正整数 `n` 和 `k`，求长度为 `k`、元素均为正整数、元素和为 `n`，且元素乘积为偶数的有序序列数量。答案对 $10^9+7$ 取模。

- $1\le n\le5\times10^5$；
- $1\le k\le n$。

**解题思路**

直接统计“至少有一个偶数”不方便，可以改用补集：

$$
\text{合法序列}=\text{全部序列}-\text{所有元素均为奇数的序列}
$$

首先用隔板法计算全部正整数序列。方程：

$$
a_1+a_2+\cdots+a_k=n,\qquad a_i\ge1
$$

的有序解数量为：

$$
T=\binom{n-1}{k-1}
$$

乘积为奇数当且仅当所有元素都是奇数。令：

$$
a_i=2b_i+1,\qquad b_i\ge0
$$

代入总和可得：

$$
b_1+b_2+\cdots+b_k=\frac{n-k}{2}
$$

当 `n - k` 为奇数时，全奇数序列不存在。否则再次使用隔板法，全奇数序列数量为：

$$
O=\binom{\frac{n-k}{2}+k-1}{k-1}
=\binom{\frac{n+k-2}{2}}{k-1}
$$

所以最终答案为：

$$
\binom{n-1}{k-1}
-[n-k\text{ 为偶数}]
\binom{\frac{n+k-2}{2}}{k-1}
$$

预处理阶乘和逆阶乘，即可 $O(1)$ 计算每个组合数。第二个组合数的上标不超过 $n-1$，因此只需预处理到 `n`。

**代码**

```cpp
class Solution {
    static constexpr int MOD = 1'000'000'007;

    long long power(long long a, long long b) {
        long long ans = 1;

        while (b > 0) {
            if (b & 1) {
                ans = ans * a % MOD;
            }
            a = a * a % MOD;
            b >>= 1;
        }

        return ans;
    }

public:
    int countValidSequences(int n, int k) {
        vector<long long> factorial(n + 1);
        vector<long long> inverseFactorial(n + 1);

        factorial[0] = 1;
        for (int i = 1; i <= n; i++) {
            factorial[i] = factorial[i - 1] * i % MOD;
        }

        inverseFactorial[n] = power(factorial[n], MOD - 2);
        for (int i = n; i >= 1; i--) {
            inverseFactorial[i - 1] = inverseFactorial[i] * i % MOD;
        }

        auto combination = [&](int a, int b) -> long long {
            if (b < 0 || b > a) {
                return 0;
            }

            return factorial[a]
                * inverseFactorial[b] % MOD
                * inverseFactorial[a - b] % MOD;
        };

        long long ans = combination(n - 1, k - 1);

        if ((n - k) % 2 == 0) {
            int top = (n + k - 2) / 2;
            ans = (ans - combination(top, k - 1) + MOD) % MOD;
        }

        return ans;
    }
};
```

**正确性说明**

隔板法枚举了全部长度为 `k`、和为 `n` 的正整数有序序列。一个整数乘积为奇数当且仅当每个因子均为奇数；变量替换 $a_i=2b_i+1$ 又在全奇数序列与上述非负整数方程的解之间建立了一一对应。因此从全部序列中减去全奇数序列后，剩下的恰好是乘积为偶数的序列。

**复杂度分析**

时间复杂度：$O(n)$。

空间复杂度：$O(n)$。

**变形**

若要求乘积为奇数，答案就是被减去的全奇数方案数。若要求恰好有 `r` 个偶数，可以先选择偶数所在的 $r$ 个位置，再分别将偶数写成 $2x+2$、奇数写成 $2x+1$，最后继续用隔板法计数。

## 4003 - Minimum Cost Path with Alternating Directions III

**题意**

题目链接：[Minimum Cost Path with Alternating Directions III](https://leetcode.com/problems/minimum-cost-path-with-alternating-directions-iii/description/)

给定一个 `m x n` 网格和罚款矩阵 `penalty`，从 `(0, 0)` 到达 `(m - 1, n - 1)`。进入 `(i, j)` 的费用为 $(i+1)(j+1)$，起点的进入费用也需要支付。

动作编号从 `1` 开始：

- 奇数次动作向右或向下符合规则；
- 偶数次动作向左或向上符合规则；
- 违反方向规则时，在目的格进入费用之外，还要支付出发格的 `penalty`；
- 也可以留在原地等待一次，费用为当前格的 `penalty`。

每次移动或等待后，动作编号的奇偶性都会翻转。求到达终点的最小费用。

- $2\le mn\le10^5$；
- $0\le penalty[i][j]\le10^5$。

**解题思路**

只记录当前位置不够。到达同一个格子时，下一次动作的奇偶性不同，合法移动方向和后续费用也会不同。因此定义两层状态：

$$
dist[i][j][p]
$$

其中：

- `p = 0`：下一次是奇数动作；
- `p = 1`：下一次是偶数动作。

从状态 `(i, j, p)` 有两类转移。

1. 原地等待：

$$
(i,j,p)\rightarrow(i,j,p\oplus1)
$$

边权为 `penalty[i][j]`。

2. 移动到相邻格子 `(x, y)`：

$$
(i,j,p)\rightarrow(x,y,p\oplus1)
$$

首先支付目的格进入费用 $(x+1)(y+1)$；如果方向不符合当前奇偶规则，再加上 `penalty[i][j]`。

所有边权均非负，所以在这张包含 `2mn` 个节点的分层图上运行 Dijkstra。初始已经支付起点进入费用，且下一次是奇数动作：

$$
dist[0][0][0]=1
$$

**代码**

```cpp
class Solution {
public:
    long long minCost(int m, int n, vector<vector<int>>& penalty) {
        const long long INF = 1LL << 62;
        int totalStates = 2 * m * n;

        vector<long long> dist(totalStates, INF);
        vector<pair<int, int>> directions = {
            {-1, 0},
            {1, 0},
            {0, -1},
            {0, 1}
        };

        using State = pair<long long, int>;
        priority_queue<State, vector<State>, greater<State>> pq;

        // id = 2 * (i * n + j) + parity
        // parity = 0 表示下一次是奇数动作。
        dist[0] = 1;
        pq.push({1, 0});

        while (!pq.empty()) {
            auto [currentDistance, state] = pq.top();
            pq.pop();

            if (currentDistance != dist[state]) {
                continue;
            }

            int parity = state & 1;
            int cell = state / 2;
            int row = cell / n;
            int column = cell % n;

            // 等待一次。
            int nextState = 2 * cell + (parity ^ 1);
            long long nextDistance =
                currentDistance + penalty[row][column];

            if (nextDistance < dist[nextState]) {
                dist[nextState] = nextDistance;
                pq.push({nextDistance, nextState});
            }

            for (auto [deltaRow, deltaColumn] : directions) {
                int nextRow = row + deltaRow;
                int nextColumn = column + deltaColumn;

                if (nextRow < 0 || nextRow >= m ||
                    nextColumn < 0 || nextColumn >= n) {
                    continue;
                }

                bool followsRule;
                if (parity == 0) {
                    followsRule = (deltaRow == 1 || deltaColumn == 1);
                } else {
                    followsRule = (deltaRow == -1 || deltaColumn == -1);
                }

                long long moveCost =
                    1LL * (nextRow + 1) * (nextColumn + 1);

                if (!followsRule) {
                    moveCost += penalty[row][column];
                }

                int nextCell = nextRow * n + nextColumn;
                nextState = 2 * nextCell + (parity ^ 1);
                nextDistance = currentDistance + moveCost;

                if (nextDistance < dist[nextState]) {
                    dist[nextState] = nextDistance;
                    pq.push({nextDistance, nextState});
                }
            }
        }

        int target = 2 * (m * n - 1);
        return min(dist[target], dist[target + 1]);
    }
};
```

**正确性说明**

当前位置和下一次动作的奇偶性足以决定所有后续可选动作及费用，因此 `(i, j, p)` 是完整状态。每次等待或移动都与分层图中的一条边一一对应，且边权与题目规定费用完全相同；反过来，图中每条边也对应一个合法动作。于是原问题的行动序列与状态图路径保持费用相等。所有边权非负，Dijkstra 能正确求出两个终点状态的最短距离，二者最小值即为答案。

**复杂度分析**

令 $N=mn$。状态数为 $2N$，每个状态最多有一条等待边和四条移动边。

时间复杂度：$O(N\log N)$。

空间复杂度：$O(N)$。

**知识点总结**

当“同一位置在不同时间阶段具有不同转移规则”时，需要把周期状态加入节点。本题只关心动作编号模 `2` 的结果，因此建立两层图即可。类似地，规则每 `k` 步循环时，可以建立 `(position, time % k)` 的 `k` 层状态图。
